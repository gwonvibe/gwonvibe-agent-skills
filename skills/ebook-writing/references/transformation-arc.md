# 독자의 변화 경로 설계

전자책의 변화는 거창한 인생 변화가 아니라 읽기 전에는 어려웠던 일을 읽은 뒤 스스로 해내는 것이다.

## 세 칸으로 시작한다

```text
현재 상태 → 책에서 거칠 단계 → 확인 가능한 도달 결과
```

### 현재 상태

독자가 이미 아는 것과 아직 하기 어려운 것을 구분한다.

- 어떤 상황에서 막히는가
- 지금은 무엇을 하고 있는가
- 어떤 결과가 반복해서 잘못되는가
- 이미 가진 도구나 경험은 무엇인가

독자를 “의지가 없는 사람”처럼 평가하지 말고 관찰 가능한 상황을 쓴다.

### 도달 결과

감정이나 정체성보다 확인 가능한 행동과 결과물을 쓴다.

```text
막연함: 자신감 있는 창업자가 된다.
구체적임: 고객 한 명, 해결할 문제 하나, 첫 제안을 한 페이지에 정리한다.
```

책이 보장할 수 없는 매출, 합격, 성공을 결과로 약속하지 않는다.

### 책에서 거칠 단계

도달 결과를 만들기 위해 필요한 중간 결과를 거꾸로 찾는다.

```text
최종 결과
└─ 바로 전에 필요한 결과
   └─ 그 결과를 만들기 위한 판단
      └─ 처음 준비할 정보
```

각 단계는 다음 단계에서 실제로 쓰여야 한다. 쓰이지 않는 지식은 부록으로 옮기거나 뺀다.

## 변화 지도 양식

```markdown
## 독자
- 대상:
- 사용하는 상황:
- 이미 아는 것:

## 현재 상태
- 혼자 하기 어려운 일:
- 자주 생기는 문제:
- 확인할 수 있는 근거:

## 도달 결과
- 완성할 결과물:
- 직접 할 수 있어야 하는 행동:
- 완료를 확인하는 방법:

## 연결 단계
1. 준비:
2. 첫 결과:
3. 판단 또는 개선:
4. 실제 적용:
5. 최종 확인:
```

단계 수는 주제에 맞게 늘리거나 줄인다.

## 장과 연결하기

각 장을 변화 지도에 대입한다.

| 장 | 시작할 때 가진 것 | 장에서 하는 일 | 끝날 때 남는 것 |
|---|---|---|---|
| 예시 | 흩어진 고객 메모 | 반복되는 문제를 묶는다 | 우선순위가 있는 문제 목록 |

“끝날 때 남는 것”이 없고 다음 장에서도 쓰이지 않으면 그 장의 역할을 다시 검토한다.

## 감정과 이야기를 사용할 때

독자의 불안이나 기대를 이해하는 것은 도움이 되지만 모든 책에 극적인 서사가 필요한 것은 아니다.

- 사례가 핵심인 책: 선택과 결과의 흐름을 이야기로 보여줄 수 있다.
- 실습 안내서: 감정보다 단계와 오류 해결을 우선한다.
- 참고서: 처음부터 끝까지 읽지 않아도 찾기 쉬운 구조를 우선한다.

불안을 과장하거나 독자를 무능하게 묘사해 행동을 유도하지 않는다.

## 최종 확인

- 현재 상태와 도달 결과가 관찰 가능한 말로 적혔는가
- 책만 읽어도 중간 단계를 따라갈 수 있는가
- 각 장의 결과물이 다음 장에서 쓰이는가
- 독자가 이미 안다고 가정한 필수 지식이 없는가
- 성공을 보장하거나 근거 없이 정체성 변화를 약속하지 않는가
