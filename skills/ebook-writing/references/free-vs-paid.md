# 무료판과 유료판 설계

무료판은 미완성 미끼가 아니라 좁은 문제를 독립적으로 해결하는 작은 제품이다. 유료판은 더 넓은 범위, 더 깊은 설명, 실행 도구나 지원으로 가치를 확장한다.

## 기본 구분

| 항목 | 무료판 | 유료판 |
|---|---|---|
| 목표 | 한 가지 좁은 결과를 완성 | 더 크거나 반복 가능한 결과를 완성 |
| 범위 | 핵심 상황 하나 | 여러 상황과 선택지 |
| 설명 | 실행에 필요한 만큼 | 원리, 변형, 예외까지 |
| 예시 | 대표 예시 | 다양한 조건의 예시 |
| 문제 해결 | 흔한 막힘 | 복잡한 오류와 대안 |
| 도구 | 간단한 체크리스트나 양식 | 워크북, 템플릿, 사례 모음 등 |
| 지원 | 스스로 실행 가능 | 필요할 때 피드백·업데이트·커뮤니티 등 |

실제 제공하지 않는 지원은 약속하지 않는다.

## 무료판이 지켜야 할 것

- 표지와 설명에서 약속한 결과를 혼자서 완성할 수 있다.
- 핵심 단계나 안전 주의를 의도적으로 빼지 않는다.
- 유료판을 사지 않아도 배운 내용을 적용할 수 있다.
- 유료판 안내는 선택 가능한 다음 단계로 분명히 구분한다.

## 유료판이 값을 만드는 방법

- 여러 상황에 적용할 판단 기준을 제공한다.
- 실패 사례와 수정 과정을 보여준다.
- 반복 작업을 줄이는 양식이나 템플릿을 제공한다.
- 실제 사례를 근거와 함께 깊이 해설한다.
- 최신 정보가 중요한 주제라면 업데이트 범위와 기간을 명시한다.
- 피드백이나 지원이 포함되면 대상, 방식, 한계를 구체적으로 알린다.

## 나누는 순서

1. 독자가 원하는 최종 결과를 적는다.
2. 그 결과를 작은 결과들로 나눈다.
3. 무료판 하나만으로 완성할 수 있는 작은 결과를 고른다.
4. 유료판에서 추가되는 범위와 깊이를 표로 비교한다.
5. 두 버전 모두 제목과 설명이 실제 내용과 맞는지 확인한다.

분량을 먼저 정해 내용을 억지로 늘리거나 줄이지 않는다. 필요한 설명과 예시가 끝나는 곳이 적절한 길이다.

## 안내 문구 예시

```text
이 무료 안내서만으로 [좁은 결과]까지 완성할 수 있습니다.
여러 상황에 적용하는 방법, 추가 사례, 실전 양식이 필요하다면
유료판에서 [구체적인 추가 가치]를 확인할 수 있습니다.
```

가짜 마감, 근거 없는 할인, 의도적으로 만든 결핍은 사용하지 않는다.
