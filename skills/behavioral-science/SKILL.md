# Behavioral Science

소비자 행동을 기능·감정·맥락에서 해석하는 제한된 가설 도구다. 이 개인 독서 메모를 검증된 인과 법칙으로 취급하지 않는다.

## 판단 순서

1. 사용자의 목표, 관찰 사실, 모르는 원인을 나눈다. 로그·기능 오류 등 직접 근거가 있으면 추정 심리보다 먼저 확인한다.
2. 주어진 수치의 대상·분모·단계를 보존한다. 일부 집단의 오류 기록만으로 나머지 전원을 무오류 집단으로 만들지 않는다. 전체 이탈 지표와 원인별 분석은 별개다.
3. 설명이 더 필요할 때 가치 인식·갈등·자기 발견 중 근거와 맞는 가설을 선택한다.
4. 그 가설을 구별할 최소 관찰·시험을 제안한다. 미측정 효과를 전환 증가나 충성도 향상으로 확정하지 않는다. 분석 요청만으로 구현을 바꾸지 않는다.

## 참여와 마찰

- 개인화·탐색은 이해나 실제 사용 가치에 도움이 될 때 선택적으로 제공한다. 이미 가능한 빠른 완료 경로에 기억·몰입만을 위한 필수 단계나 대기를 추가하지 않는다.
- 필수 여부는 기능 성립·안전·필수 정보에 근거해 판단한다. 필요한 보안 확인까지 무조건 없애지 않는다.
- 선택 기능에는 찾기 쉬운 건너뛰기·되돌리기를 유지한다. 참여율을 높이려 선택권을 숨기거나 덜 눈에 띄게 만들지 않는다.
- 질문·직접 만들기의 효과는 가설이다. 모든 사람에게 답 대신 탐색을 요구하지 않는다.
