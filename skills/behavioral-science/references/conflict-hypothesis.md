# 갈등 가설 관찰 가이드

고객이 원하는 결과와 피하고 싶은 비용·위험을 함께 말할 때 갈등 가설을 검토한다.

## 정리 방법

1. 인터뷰 원문이나 실제 행동을 먼저 적는다.
2. “A를 원하지만 B는 피하고 싶다” 형태로 임시 정리한다.
3. A와 B가 자료에 직접 나타났는지 확인한다.
4. 정보 부족·가격·기능 오류·시기 문제 같은 다른 설명을 함께 둔다.
5. 후속 질문이나 행동 비교로 두 설명을 구별한다.

예시:

- 관찰: 자동화를 원한다고 말했지만 모든 자동 실행을 꺼두었다.
- 갈등 가설: 반복 작업은 줄이고 싶지만 결과를 확인하지 못한 채 실행되는 것은 피하고 싶다.
- 다음 확인: 자동화 자체와 승인 없는 실행 중 무엇이 부담인지 묻고, 미리보기·승인 단계가 있을 때 사용 여부를 비교한다.

자료에 없는 욕구·집단·수치를 만들지 않는다. 기능 오류나 고객의 직접 진술을 ‘무의식’ 같은 말로 덮어쓰지 않는다.

참고 관점: 호소다 다카히로, 《컨셉수업》. 위 절차는 고객 발언을 검증 가능한 가설로 다루도록 독자적으로 재구성했다.
