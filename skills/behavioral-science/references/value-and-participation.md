# 가치·탐색·참여 가설 가이드

고객이 무엇을 가치 있게 느끼는지, 직접 탐색하거나 참여하는 과정이 실제 사용에 도움이 되는지 살필 때 사용한다.

## 가치 인식

같은 기능도 고객은 서로 다른 이유로 선택할 수 있다.

- **기능 가치:** 시간 절약, 오류 감소, 결과물 완성
- **감정 가치:** 안심, 부담 감소, 자신감
- **정체성 가치:** 자신이 되고 싶은 모습이나 일하는 방식과의 일치

어느 가치가 중요한지는 고객의 말과 행동으로 확인한다. 감정이나 정체성을 실제 기능 문제보다 앞세워 추정하지 않는다.

## 탐색과 참여

질문·비교·직접 만들기가 도움이 될 수 있는 경우:

- 고객이 선택 기준을 이해해야 하는 경우
- 개인 조건에 따라 답이 달라지는 경우
- 직접 만든 결과를 이후에도 사용하는지 확인할 수 있는 경우

빠른 기본 경로가 더 적절한 경우:

- 정답이 명확하고 즉시 완료가 중요한 경우
- 반복 작업에서 매번 같은 선택을 요구하는 경우
- 추가 단계가 이해보다 피로만 늘리는 경우

효과는 완료율, 이후 사용률, 오류율, 인터뷰 반응처럼 행동과 연결된 자료로 확인한다. 참여 단계에 들어간 사람만 보고 전체 고객에게 효과가 있었다고 결론내리지 않는다.

참고 관점: 호소다 다카히로, 《The Sense》. 위 기준은 발견과 참여를 강제 규칙이 아닌 검증 가능한 경험 가설로 재구성했다.
