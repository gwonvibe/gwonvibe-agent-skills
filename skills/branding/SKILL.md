# Branding

브랜드가 **누구에게 어떤 가치를 약속하고, 실제 경험으로 어떻게 지킬지** 정리하는 스킬이다. 로고·색상·말투만 다루는 작업이 아니며, 감정적인 표현이 실제 가치와 고객 근거를 대신하지 않는다.

## 먼저 요청 범위를 정한다

- **새 방향 설계:** 고객·제공 가치·약속의 빈칸을 확인한다.
- **기존 브랜드 검토:** 이미 확정된 방향과 실제 제품·서비스 경험이 맞는지 본다.
- **부분 수정:** 요청받은 문장이나 결정만 다루고 전체 전략을 다시 만들지 않는다.

주어진 미션·고객·운영 조건은 재사용한다. 필요한 정보가 없으면 결과를 크게 바꾸는 질문만 하고, 고객 반응·경쟁 우위·성과를 자료 없이 만들어내지 않는다.

## 작업 순서

### 1. 브랜드 약속 한 줄

다음 네 칸을 채운다.

```text
[우선 고객]이 [구체적인 상황]에서 [얻는 가치]를 [우리가 실제로 제공하는 방식]으로 돕는다.
```

‘모든 사람’을 억지로 배제할 필요는 없다. 먼저 만족시킬 고객과 그 이유를 명확히 한다.

### 2. 근거와 경계

- 현재 제품·서비스가 실제로 제공하는 것은 무엇인가?
- 약속을 믿게 할 경험·후기·운영 방식·성과 자료가 있는가?
- 아직 바라는 미래일 뿐인 내용은 무엇인가?
- 고객에게 보장할 수 없는 결과는 무엇인가?

희망하는 변화와 현재 제공 가능한 약속을 구별한다.

### 3. 브랜드 구조 정렬

미션·비전·컨셉·가치를 함께 다룰 때는 `references/brand-alignment.md`를 읽는다. 이미 확정된 항목은 새로 만들지 않고 서로 충돌하는지만 확인한다.

### 4. 고객 경험 확인

로고·색상·포장을 빼도 고객이 선택할 이유가 남는지 확인한다. 관계와 시간 경험을 살펴볼 때는 `references/customer-relationship.md`를 읽는다.

### 5. 필요한 관점만 검토

전체 검토나 관점 선택이 필요하면 `references/brand-review-guide.md`를 사용한다. 모든 항목을 의무적으로 채우지 않는다.

## 판단 원칙

- 멋있는 표현보다 실제 선택 이유를 우선한다.
- 미래상은 방향이고, 고객 결과 보장은 아니다.
- 가치 선언은 실제 행동 규칙과 연결돼야 한다.
- 비사용 시간의 접점은 고객에게 도움이 될 때만 제안한다. 알림·방문 빈도를 늘리는 것을 기본값으로 삼지 않는다.
- 새로운 컨셉이나 판매 문구가 필요해도 이 스킬 안에서 기본 초안은 만들 수 있다. 다른 스킬이 설치돼 있다면 심화 작업에 선택적으로 연결한다.

## 출력

요청 범위에 맞게 다음 중 필요한 것만 제시한다.

- 브랜드 약속 한 줄
- 우선 고객·상황·가치·제공 방식
- 확인된 근거와 아직 확인되지 않은 주장
- 미션·비전·컨셉·가치의 충돌 또는 빈칸
- 유지할 것, 수정할 것, 다음 확인 하나

## 요청 예시

- “우리 서비스 소개와 실제 제공 기능이 같은 약속을 하고 있는지 검토해줘.”
- “미션·비전·컨셉이 서로 겹치는데 초보자도 이해할 수 있게 정리해줘.”
- “로고와 색을 빼도 고객이 우리를 선택할 이유가 남는지 봐줘.”
- “이 슬로건 한 문장만 브랜드 방향에 맞게 고쳐줘. 전체 진단은 하지 마.”

## 선택적 후속 연결

다른 스킬이 설치돼 있다면 상세 컨셉 발상은 `concept-design`, 지식상품 판매 문구는 `digital-product-copy`로 이어갈 수 있다. 없어도 현재 요청의 결과는 이 스킬에서 완성한다.
