# 미션·비전·컨셉·가치 정렬 가이드

네 항목은 역할이 다르다.

| 항목 | 답할 질문 | 좋은 상태 |
|---|---|---|
| 미션 | 왜 이 일을 계속하는가? | 특정 상품이 바뀌어도 남는 목적 |
| 비전 | 우리가 잘되면 어떤 미래가 만들어지는가? | 그림이 그려질 만큼 구체적이지만 성과 보장은 아님 |
| 컨셉 | 지금 고객에게 어떤 관점과 방식으로 가치를 제공하는가? | 제품·콘텐츠·디자인의 선택 기준이 됨 |
| 가치 | 중요한 순간에 어떻게 행동하고 결정하는가? | 멋있는 단어가 아니라 선택·거절 기준으로 작동함 |

## 정렬 순서

1. 이미 확정된 문장을 그대로 모은다.
2. 각 문장이 위 네 역할 중 어디에 해당하는지 분류한다.
3. 같은 뜻이 반복되면 가장 적합한 한 위치에 둔다.
4. 서로 반대되는 약속이나 행동을 찾는다.
5. 비어 있는 항목이 현재 요청에 꼭 필요한지 판단한다.
6. 수정안은 실제 제공 능력과 고객 근거를 넘지 않게 쓴다.

비전은 현재 능력의 단순 반복보다 앞을 보되, 실행 경로나 근거가 전혀 없는 거대한 문장만 남기지 않는다. 컨셉이 독특해 보인다는 이유로 고객 공감·시장 규모·경쟁 우위가 확인됐다고 판정하지 않는다.

참고 관점: 호소다 다카히로, 《컨셉수업》. 위 구분과 절차는 브랜드 문서의 역할과 충돌을 실무에서 확인하도록 독자적으로 재구성했다.
