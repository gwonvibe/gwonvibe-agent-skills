# Branding — 핵심 관점

개인 독서 메모의 적용 안내다. 책별 요약은 `the-sense.md`, `concept-lesson.md`에 두고 필요한 설명만 읽는다. 책 원문·고객 조사를 대신하지 않는다.

| 관점 | 판단에 쓸 질문 | 상세 메모 |
|---|---|---|
| 맨얼굴 | 포장을 빼도 선택할 실제 이유가 있는가? | the-sense.md |
| 컨셉 | 일관된 “왜”가 제품·마케팅·디자인의 판단을 돕는가? | concept-lesson.md |
| 미션·비전·컨셉 | 사명·미래상·지금의 역할이 충돌하지 않는가? | concept-lesson.md |
| 가치(Values) | 선언이 실제 행동과 연결되는가? | concept-lesson.md |

| 시간 경험 | 시간을 아끼는지 머무는지, 고객에게 어떤 의미인가? | the-sense.md |

## 적용 경계

- 미션·비전이 확정된 요청에 새 전략 작업을 강제하지 않는다. 상세 컨셉 발상은 concept-design이 맡는다.
- “가장 좋아할 한 명”은 고객을 구체화하는 관점이지 넓은 수요를 근거 없이 부정하는 법칙이 아니다.
- 감정·미래상을 실제 고객 반응·경쟁 우위의 증거로 쓰지 않는다.
- 제로 시간은 비사용 시간을 살펴보는 관점이다. 추가 접점이 고객에게 도움이 될 때만 발견 → 역할 정의 → 경험 설계를 검토한다. 이용 주기·비경쟁 방향을 임의로 바꾸지 않는다.
- 일반 브랜드의 맨얼굴 테스트는 “포장을 빼도 남는 가치”다. 권바이브 개인본의 “직접 말해도 부끄럽지 않은 약속”과 같은 검사로 합치지 않는다.
