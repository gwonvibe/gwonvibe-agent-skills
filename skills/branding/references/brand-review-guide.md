# 브랜드 검토 관점

요청에 필요한 관점만 고른다. 빈칸이 있다는 이유로 모든 브랜드 문서를 새로 만들지 않는다.

| 관점 | 확인 질문 | 필요한 근거 |
|---|---|---|
| 선택 이유 | 시각 요소를 빼도 고객이 고를 이유가 남는가? | 실제 기능, 품질, 경험, 운영 방식 |
| 우선 고객 | 누구의 어떤 상황을 먼저 해결하는가? | 인터뷰, 구매·사용 자료, 명확한 사업 선택 |
| 브랜드 약속 | 원하는 변화와 현재 제공 가치가 연결되는가? | 상품 구성, 제공 절차, 확인된 성과 |
| 일관된 관점 | 제품·콘텐츠·디자인을 판단할 공통 기준이 있는가? | 반복되는 결정 원칙과 실제 적용 사례 |
| 미션·비전 | 존재 이유와 만들고 싶은 미래가 구별되는가? | 창업자의 결정, 조직의 합의 |
| 행동 가치 | 선언한 가치가 구체적인 행동을 바꾸는가? | 선택·거절·운영 기준 |
| 시간 경험 | 시간을 아껴주는지, 머물 가치가 있는 경험인지 분명한가? | 사용 흐름, 이용 주기, 고객 반응 |

## 판정

- **정렬됨:** 약속·근거·경험이 같은 방향이다.
- **충돌:** 말하는 약속과 실제 제공 방식이 다르다.
- **미확인:** 고객 근거나 운영 자료가 없어 아직 판단할 수 없다.

감정적인 표현과 자체 확신만으로 `정렬됨`이라고 판정하지 않는다. 미확인 항목은 확인할 자료나 질문 하나를 붙인다.
