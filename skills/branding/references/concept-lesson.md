# 컨셉수업 — 호소다 다카히로 (Branding)

개인 독서 메모다. 아래 사례는 개념 설명용이며 해당 기업의 현재 공식 전략을 확인한 자료가 아니다. 상세 컨셉 발상은 concept-design의 역할이고 여기서는 기존 방향과 약속의 정합성을 본다.

## 컨셉 = 가치의 설계도

**핵심**: 컨셉은 전체를 관통하는 새로운 관점이자 가치의 설계도

1. 판단 기준이 된다
2. 일관성을 부여한다
3. 대가의 이유가 된다

흔들림 없는 '왜'가 중심에 있어야 '무엇을', '어떻게'를 시대에 맞게 업데이트 가능.

**적용**: 브랜드 전략 수립 시 '왜'(컨셉)를 먼저 확립하고, 제품/마케팅/디자인은 그 '왜'의 구성요소로 설계한다.

**출처**: 컨셉수업 — 호소다 다카히로

## 미션-비전-컨셉 3층 구조

**핵심**: 미션(영원한 사명) → 비전(이상적 미래) → 컨셉(지금의 최선)

- 미션: '지금껏 만든 것이 수단이라면, 진짜 목적은?' 보편성 + 고유성
- 비전: '보이는 언어'로. 스케치 가능할 정도로 구체적. 스트레치 존에서 설정
- 컨셉: 비전을 향한 첫걸음. 고객 인사이트와 비전 양쪽을 만족

SpaceX: 미션 '인류의 밝은 미래' → 비전 '여러 행성 거주' → 컨셉 '재사용 로켓'

**적용**: 브랜드 비전 문서 작성 시 3층 구조로 정렬. 컨셉이 미션과 비전 사이 연결 고리인지 검증.

**출처**: 컨셉수업 — 호소다 다카히로

## 비전의 스트레치 존

**핵심**: 비전은 컴포트(쉬움)와 패닉(비현실) 사이, 스트레치 존에서 써야 한다

- 컴포트 존: 현재 능력 범위, 심리적 부담 없음
- 스트레치 존: 기존 방식으론 안 되지만 비현실적이지도 않음
- 패닉 존: 영원히 실현 안 될 것 같음

해상도 높이기: '스포츠로 건강하게' → '모든 100세 노인이 100m를 달릴 수 있는 시대로'

**적용**: 비전 초안 작성 후 3존 중 어디인지 검증. 스트레치가 아니면 조정.

**출처**: 컨셉수업 — 호소다 다카히로

## 가치(Values) 설계

**핵심**: 조직 공유 가치관과 행동 원칙을 짧고 인상적인 문구로

**3단계**: 발굴(행동 전부 꺼내기) → 선정(미션/비전과 대조) → 언어화(간단, 명확, 기억하기 쉽게)
**3조건**: 간단하게 / 명확하게 / 기억하기 쉽게 (운율, 리듬)

**적용**: 브랜드 가치 정의 시 행동 기반으로 발굴하고, 비전/미션과 정렬 확인 후 언어화.

**출처**: 컨셉수업 — 호소다 다카히로

## 효과적인 컨셉 4조건

**핵심**: 완성된 컨셉을 검증하는 4가지 필터

1. 고객 눈높이 — 기뻐하는 고객 얼굴이 떠오르는가
2. 세상에 단 하나 — 우리만의 것인가 (미움받을 각오)
3. 규모 예측 — 비즈니스 목표 달성 가능한 규모인가
4. 쉬운 말 — 짧고 기억하기 쉽고 공유 가능한가

**적용**: 컨셉 최종 확정 전 필요한 조건을 점검한다. 실제 고객 공감·유일성·규모는 관련 자료가 없으면 미확인이며, 자체 평가만으로 통과 등급을 붙이지 않는다.
