# 콘텐츠 심리 설계

> 출처: `references/content-psychology-technique-library-v0.md` v0.3의 연구 기반 카드·공개 실무 사례와 사용자 대화에서 합의한 윤리 기준.

## 원칙

- 콘텐츠 구조(OREO, AIDA, PAS)를 심리학 법칙처럼 설명하지 않는다.
- 유명 크리에이터의 사례와 연구 근거를 분리한다. 성과 주장은 공개 지표·출처가 있을 때만 말한다.
- 조회수 대신 사용자가 원하는 행동 하나를 먼저 정한다: 멈춤, 이해, 저장, 공유, 팔로우, 클릭, 신청.
- 가짜 희소성·허위 사회적 증거·공포·수치심·취약성 악용을 쓰지 않는다.

## 작업 흐름

### 0. 주제 선정

플랫폼을 고르기 전에 주제 브리프를 먼저 만든다. 사용자가 주제를 줬더라도 너무 넓으면 같은 기준으로 관점을 좁힌다.

1. 채널의 역할 또는 이번 콘텐츠의 목적, 시청자의 실제 문제 순간, 활용할 수 있는 근거·사례·데모를 찾는다. 정보가 비어 있으면 현재 대화·보유 자산에서 합리적으로 추론하고 `가정`이라고 밝힌다.
2. 아래 형식으로 후보를 최대 3개만 만든다. `시청자 문제 순간 → 이 콘텐츠에서 얻을 구체적 판단/변화 → 보여줄 근거`.
3. **채널 적합성, 문제의 구체성, 보여줄 근거** 세 가지가 모두 있는 후보 하나를 고른다. 근거가 없으면 권위 있는 조언처럼 만들지 말고 실험·질문형으로 낮춘다.
4. `시청자 / 문제 순간 / 선택 주제와 관점 / 근거 / 이번 콘텐츠의 목표 행동`으로 주제 브리프를 낸다. 그 뒤에만 플랫폼과 결과물을 고른다.

외부 트렌드·경쟁 콘텐츠에서 후보를 찾아야 하면 해당 플랫폼의 리서치 스킬을 먼저 쓴다. 채널의 고객·상품·퍼널 목적 자체가 불명확하면 `growth-marketing`으로 정한 뒤 돌아온다.

### 1. 요청 분류

다음 중 하나로 분류한다.

- **발견 분석:** 링크·대본·기법 주장을 받아 원리, 구조, 과장을 분리한다.
- **주제 선정:** 주제가 비었거나 넓을 때 후보·선택 근거·주제 브리프를 만든다.
- **콘텐츠 설계:** 0단계의 주제 브리프를 바탕으로 플랫폼별 제목·훅·대본·화면·CTA를 만든다.
- **초안 점검:** 기존 콘텐츠의 심리적 병목과 최소 수정안을 제시한다.
- **새 기법 리서치:** 원전·메타분석·체계적 검토를 우선해 후보 카드를 판정한다.

목표 행동이 비어 있으면 콘텐츠의 요청 동사와 플랫폼 특성에서 합리적으로 추론하고, 추론임을 한 줄로 밝힌다. 그 때문에 작업을 멈추지 않는다.

### 2. 카드 선택

`references/content-psychology-technique-library-v0.md`에서 목표 행동에 맞는 **주원리 1개 + 보조원리 1개**만 고른다. 필요할 때만 구조 카드 1개를 추가한다.

- 멈춤·클릭: 정보 격차 또는 상대적 시각 고립 + 자기참조·구체성 또는 방향성 시선 단서
- 이해·완주: 인지부하 절감·시각적 신호화 또는 시각적 그룹화 + 완성된 예시 또는 관련 없는 흥밋거리 제거
- 저장: 완성된 예시 + 자기설명 질문 또는 생성 효과
- 공유: 실용적 가치 + 서사 몰입 또는 정체성 관련성
- 신뢰: 출처 신뢰성 + 양면 메시지 또는 반박 예방
- 팔로우·재방문: 친숙성의 누적 + 간격 반복
- 신청·구매: 실행 의도형 CTA 또는 자율성 보존 CTA + 사용 장면 심상·실제 희소성 또는 선택 단순화

조건부(C) 카드인 유머·희소성·선택 단순화는 조건과 역효과를 같이 말한다.

### 3. 산출

**발견 분석**에는 아래를 낸다.

1. 관찰된 기법과 실제 구조
2. 작동할 수 있는 심리 원리와 근거 등급
3. 원본 주장에서 과장된 부분
4. 적합한 목적·지표·오용 위험

**콘텐츠 설계**에는 아래를 낸다.

1. 주제 브리프와 목표 행동
2. 선택한 원리 조합
3. 제목 또는 첫 화면 문구 3개
4. 플랫폼에 맞는 짧은 대본·게시물 구조
5. 필요한 화면·이미지·편집 단서
6. 구체적인 CTA와 확인할 지표 1개

**주제 선정**에는 후보 3개 이내, 선택 근거, 주제 브리프만 낸다. 플랫폼별 대본을 먼저 쓰지 않는다.

**초안 점검**에는 병목 1개, 고칠 문장 또는 구간, 바뀐 이유만 낸다. 불필요한 전면 재작성을 하지 않는다.

### 4. 새 기법 리서치

- 연구 근거, 해외 실무 정착도, 공개 사례를 각각 찾는다.
- `연구 기반 / 실무 구조 / 공개 사례 / 크리에이터 주장` 중 하나로 분류한다.
- 단일 연구·바이럴 주장만 있으면 조건부 후보로 둔다.
- 라이브러리 파일을 수정·추가하는 것은 사용자가 명시적으로 요청할 때만 한다.

## 출력 문장 규칙

- `이 기법으로 조회수가 나온다` 대신 `이 기법은 [행동]의 [병목]을 줄일 가설이며, [지표]로 확인한다`라고 쓴다.
- 근거가 있는 사실에는 카드의 출처를 링크한다.
- 실제 수치·후기·마감·희소성은 제공된 사실만 쓴다.

## 다른 스킬과의 경계

- 일반 행동 설계·소비자 심리 진단은 `behavioral-science`를 함께 참조한다.
- 채널의 고객·상품·퍼널 목적은 `growth-marketing`, 외부 플랫폼·주제 트렌드는 해당 리서치 스킬을 쓴다.
- 문장 톤만 다듬는 요청은 요청 범위에서 직접 처리한다.
