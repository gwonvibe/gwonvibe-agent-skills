# 콘텐츠 심리 설계

사람을 조종하는 기술이 아니라, 시청자가 이미 가진 관심·문제·판단을 더 쉽게 이해하고 행동으로 옮기게 돕는 설계 도구다.

심리 원리와 전달 구조를 구별한다.

- **심리 원리:** 왜 주목·이해·기억·행동에 도움이 될 수 있는가
- **전달 구조:** 내용을 어떤 순서로 말할 것인가 — OREO, AIDA, PAS 등

전달 구조를 심리학 법칙이나 성과 보장 공식으로 설명하지 않는다.

## 안전 원칙

- 목표 행동은 한 콘텐츠에 하나만 고른다.
- 주원리 1개와 보조원리 1개만 사용한다.
- 실제 수치·후기·마감·희소성은 제공된 사실만 쓴다.
- 유명 크리에이터 사례와 연구 근거를 구별한다.
- 가짜 희소성·허위 사회적 증거·공포·수치심·취약성 악용을 쓰지 않는다.
- “조회수가 나온다” 대신 어떤 병목을 줄일 가설인지와 확인할 지표를 말한다.

## 작업 순서

### 1. 시청자의 문제 순간 정하기

넓은 타깃 이름보다 실제 장면을 쓴다.

```text
누가 / 어떤 순간에 / 무엇 때문에 막히는가?
```

예: `초보 크리에이터`보다 `콘텐츠를 올리려는데 첫 문장을 한 시간째 못 정하는 사람`이 구체적이다.

### 2. 보여줄 근거 확인하기

사용할 수 있는 실제 자료를 찾는다.

- 직접 보여줄 화면·전후 비교·시연
- 확인 가능한 경험·데이터·사례
- 출처를 밝힐 수 있는 연구·공식 자료
- 시청자가 바로 써볼 판단 기준·체크리스트

근거가 없으면 권위 있는 조언처럼 만들지 않고 질문·실험·개인 경험의 범위로 낮춘다.

### 3. 주제 브리프 만들기

주제가 없거나 너무 넓으면 후보를 최대 3개 만든 뒤 다음 세 조건이 가장 분명한 하나를 고른다.

- 시청자의 문제 순간이 구체적임
- 이 콘텐츠에서 얻는 판단이나 변화가 분명함
- 보여줄 근거가 있음

```text
시청자:
문제 순간:
선택한 주제와 관점:
보여줄 근거:
목표 행동:
```

외부 트렌드 조사가 꼭 필요하고 사용 가능한 검색 수단이 있으면 별도로 조사한다. 조사하지 못했다면 제공된 자료로 설계하고 `외부 트렌드 미확인`이라고 표시한다.

### 4. 목표 행동 하나 고르기

다음 중 하나를 선택한다.

`멈춤·클릭 / 이해·완주 / 저장 / 공유 / 신뢰 / 팔로우·재방문 / 신청·구매`

사용자가 정하지 않았다면 요청과 콘텐츠 목적에서 합리적으로 추론하고, 추론임을 한 줄로 밝힌다.

### 5. 원리와 구조 선택하기

`references/content-psychology-technique-library-v0.md`의 빠른 선택표에서 주원리 1개와 보조원리 1개를 고른다. 필요한 경우에만 구조 카드 1개를 더한다.

카드는 모두 채우는 체크리스트가 아니라 메뉴다. 조건부(C) 카드인 유머·희소성·선택 단순화는 적용 조건과 역효과를 함께 말한다.

### 6. 콘텐츠로 만들기

플랫폼 특성과 사용자 요청에 맞게 필요한 것만 만든다.

- 제목·썸네일 또는 첫 화면 문구
- 도입 훅
- 본문·대본의 흐름
- 화면·이미지·편집 단서
- 목표 행동과 연결된 CTA
- 게시 후 확인할 지표 하나

제목과 첫 화면이 약속한 답은 본문에서 실제로 제공한다. 클릭을 위해 결론을 숨기거나 다른 내용을 약속하지 않는다.

## 요청 유형별 출력

### 주제 선정

- 후보 최대 3개
- 선택 근거
- 주제 브리프

대본까지 요청받지 않았다면 여기서 끝낸다.

### 새 콘텐츠 설계

- 주제 브리프와 목표 행동
- 선택한 원리 2개와 적용 이유
- 제목·첫 화면 후보
- 플랫폼에 맞는 본문 구조
- CTA와 확인 지표 하나

### 기존 초안 점검

- 가장 큰 병목 하나
- 고칠 문장·장면·구간
- 최소 수정안과 이유

전면 재작성을 요청받지 않았다면 전체를 다시 쓰지 않는다.

### 기법·콘텐츠 분석

- 관찰된 기법과 전달 구조
- 연결 가능한 심리 원리와 근거 등급
- 원본 주장에서 과장된 부분
- 적합한 목적·지표·오용 위험

## 요청 예시

- “첫 문장에서 막히는 초보자를 위한 릴스 주제 세 개를 만들고 하나를 골라줘.”
- “이 대본이 왜 지루한지 심리 원리와 전달 구조를 나눠서 봐줘.”
- “저장을 목표로 제목·도입·본문·CTA를 만들어줘. 근거 없는 숫자는 쓰지 마.”
- “이 콘텐츠 전체를 다시 쓰지 말고, 이탈이 생길 만한 가장 큰 구간 하나만 고쳐줘.”

## 선택적 연결

다른 스킬이 설치돼 있다면 일반 고객 행동 가설은 `behavioral-science`, 채널·상품·퍼널 전략은 `growth-marketing`으로 더 깊게 다룰 수 있다. 없어도 주제 선정·설계·점검은 이 스킬에서 끝낸다.
