# Concept Design

컨셉은 멋있는 문장이 아니라 **여러 선택을 같은 방향으로 이끄는 관점**이다. 좋은 컨셉은 고객의 상황, 원하는 변화, 제공자의 실제 강점이 연결돼 제품·콘텐츠·디자인의 판단 기준으로 쓰인다.

## 먼저 구별한다

- **과제:** 풀어야 할 질문 — 예: 첫 사용의 부담을 어떻게 줄일까?
- **아이디어:** 가능한 해결책 하나 — 예: 시작 템플릿 제공
- **컨셉:** 여러 아이디어를 고르는 공통 관점 — 예: 빈 화면 없이 시작하는 작업대
- **카피:** 컨셉을 고객에게 표현한 문장

문구가 눈에 띈다는 이유만으로 컨셉이 되지는 않는다. 실제 선택을 바꾸지 못하면 슬로건에 가깝다.

## 입력과 경계

가능하면 다음 자료를 사용한다.

- 확정된 브랜드·미션·고객·운영 조건
- 고객 인터뷰·문의·행동에서 확인된 문제와 갈등
- 현재 대안과 고객이 불편해하는 지점
- 실제로 제공할 수 있는 기능·방식·강점

자료가 없으면 가설로 표시해 초안을 만들 수 있지만 고객 반응·유일성·시장 규모를 확정하지 않는다. 캠페인 컨셉 요청을 회사 미션 재설계로 확대하지 않고, 요청한 후보 수와 형식을 지킨다.

## 설계 흐름

### 1. 풀 과제를 한 문장으로 정리

```text
[고객]이 [상황]에서 [원하는 변화]를 얻기 어려운 이유는 무엇이며, 우리는 어떤 관점으로 바꿀 수 있는가?
```

수단부터 정하지 않는다. “앱을 어떻게 만들까?”보다 “고객이 이 일을 더 쉽게 끝내게 하려면?”처럼 목적을 먼저 확인한다.

### 2. 근거 지도 만들기

| 구분 | 적을 내용 |
|---|---|
| 확인된 고객 문제 | 실제 발언·행동·문의에서 반복된 것 |
| 고객의 갈등 | 원하지만 함께 피하고 싶은 비용·불안·노력 |
| 현재 대안의 공백 | 고객이 다른 방식에서 겪는 확인된 불편 |
| 제공자의 사실 | 기능, 경험, 자산, 운영 방식처럼 실제 보유한 것 |
| 고객에게 주는 이익 | 위 사실이 특정 고객에게 주는 변화 |
| 미확인 | 경쟁·수요·제공 가능성 중 아직 자료가 없는 것 |

사실에서 바로 컨셉으로 뛰지 않는다. “무게가 가볍다”는 사실이고, “매일 들고 다닐 수 있다”는 고객 이익이다.

### 3. 관점을 바꿔 후보 생성

후보가 잘 나오지 않으면 `references/concept-workshop.md`의 재구성 질문을 사용한다. 기본은 서로 다른 관점의 후보 3개이며, 사용자가 개수를 지정하면 그대로 따른다.

후보는 다음 구조로 먼저 풀어 쓴다.

```text
[고객]이 [상황]에서 [목적]을 이루도록,
[상품·브랜드]는 [고유한 방식]으로 [역할]을 맡는다.
```

그다음 의미를 잃지 않는 범위에서 짧게 다듬는다. 영문·유행어·짧은 글자 수를 강제하지 않는다.

### 4. 후보 비교

각 후보를 다음 기준으로 `충족 / 미확인 / 충돌`로 표시한다.

| 기준 | 확인 질문 |
|---|---|
| 고객 적합성 | 확인된 고객 상황과 원하는 변화에 닿는가? |
| 진실성 | 실제 제공 방식과 근거를 넘지 않는가? |
| 판단력 | 제품·콘텐츠·디자인의 선택 기준이 되는가? |
| 차별성 | 현재 대안과 다른 관점이 있는가? 경쟁 근거가 없으면 미확인인가? |
| 실행 가능성 | 현재 자원과 운영 조건에서 구현할 수 있는가? |
| 명료성 | 처음 보는 사람이 전문용어 없이 뜻을 이해할 수 있는가? |

자체 평가만으로 고객 공감·유일성·시장 규모를 통과 처리하지 않는다.

### 5. 최종안 정리

근거가 가장 강한 후보를 추천하되 사용자 확정과 구별한다. 표현이 새로운 자격·성과·무료 제공·운영 의무를 암시하면 주의 문구를 덧붙이는 대신 컨셉 자체를 고친다.

## 출력

요청 범위에 맞게 다음을 제시한다.

1. 풀 과제
2. 사용한 고객·대안·자사 근거
3. 컨셉 후보와 한 줄 설명
4. 후보별 `충족 / 미확인 / 충돌`
5. 추천안과 추천 이유
6. 확정 전에 확인할 가장 중요한 것 하나

단순 초안 요청에는 컨셉 문장과 짧은 설명만 제시한다. 전체 워크숍 표를 매번 출력하지 않는다.

## 요청 예시

- “초보자가 빈 화면에서 막히지 않는 글쓰기 도구 컨셉을 세 가지 만들어줘.”
- “이 고객 인터뷰와 실제 기능을 바탕으로 상품 컨셉을 만들고, 근거 없는 부분은 표시해줘.”
- “두 컨셉 중 제품·콘텐츠·디자인의 판단 기준으로 더 쓸 수 있는 쪽을 골라줘.”
- “캠페인 컨셉 한 줄만 다듬어줘. 회사 미션은 바꾸지 마.”

## 선택적 연결

다른 스킬이 설치돼 있다면 기존 브랜드 방향과의 정합성은 `branding`으로 더 확인할 수 있다. 없어도 컨셉 설계와 비교는 이 스킬에서 끝낸다.
