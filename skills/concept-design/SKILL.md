# Concept Design

호소다 다카히로의 컨셉수업을 정리한 개인 메모를 활용한다. 컨셉은 전체를 관통하는 관점이며, 예쁜 문구만이 아니라 고객·목적·역할이 연결돼야 한다.

## 범위와 근거

- 확정된 브랜드·미션·고객·운영 조건을 재사용한다. 캠페인 초안을 회사 미션 재설계로 확대하지 않는다. 운영 조건의 추가·완화는 제안이지 승인된 사실이 아니다.
- 단계별 워크숍 요청이면 아래 흐름에 따라 현재 필요한 질문을 하고 답을 기다린다. 이미 자료가 있는 초안·부분 요청은 필요한 단계만 수행한다.
- 인사이트·경쟁 기회·베네핏의 근거를 구별한다. 자료가 없으면 가설이나 미확인으로 남기며, 듣기 좋은 이야기로 빈칸을 확정하지 않는다.
- 요청한 안 수·형식을 지킨다. 자료 부족이 초안을 막지 않으면 미확인 상태를 보존해 제출한다. 확정에 꼭 필요한 선택만 질문한다.

## 설계 흐름

상세 발상법·워크숍 질문·사례가 필요한 단계에서 `references/concept-lesson.md`의 해당 절을 읽는다. 아래는 진행 안내이며 전체 표를 매번 출력하지 않는다.

| 단계 | 목적과 산출물 | 참조 절 |
|---|---|---|
| 질문 설계 | 풀 과제와 바꿀 상식을 확인해 핵심 질문을 정한다 | 질문 설계 / 재구성 7가지 방법 |
| 인사이트 발굴 | 고객의 갈등, 고객 대안의 공백, 자사 사실에서 나온 베네핏을 구별한다 | 고객 인사이트 / 경쟁자 3층 분석 / 자사 강점 분석 |
| 비전 연결 | 기존 미션·비전에 부합하는지 본다. 새로 만드는 요청일 때만 목적·미래상을 설계한다 | 미션-비전-컨셉 3층 구조 / 인사이트형 + 비전형 통합 |
| 컨셉 조립 | 고객·경쟁 기회·자사 역할의 연결이 근거에 맞는지 점검한다 | 4C 인사이트형 스토리 |
| 한 문장 다듬기 | 고객이 이해할 목적형·역할형·연결형 표현으로 다듬는다 | 3점 정리법 / 표현 감각 3법 / 9가지 문장 구문 |

조립의 중심은 **“A(고객)가 B(목적)를 이루도록 C(역할)를 맡는다”**이다. 경쟁 조사가 없으면 “아무도 돕지 못한다”는 4C 문구를 사실로 채우지 않는다.

짧고 기억하기 쉬운 표현을 지향하되, 영단어 2개 같은 요령은 글자 수 규정이나 인간 인지의 보편 한계가 아니다. 한국어에서 뜻을 잃으면서 압축하지 않는다.

## 최종 점검

| 관점 | 판단 경계 |
|---|---|
| 고객 눈높이 | 제공된 고객·문제와 연결되는가? 실제 고객 공감은 반응 자료가 없으면 미확인이다. |
| 고유성 | 차별화 아이디어와 입증된 유일성을 구별한다. 경쟁 조사가 없으면 “우리만 가능”이나 긍정 등급을 붙이지 않는다. |
| 규모 | 시장·수요·제공 여력의 근거가 있는가? 문장이 좋아도 사업 규모는 미확인일 수 있다. |
| 쉬운 말 | 뜻이 명확한지 자체 검토한다. 실제 기억·공유 효과 시험과 구별한다. |

표를 출력한다면 각 항목에 근거 있는 판단 또는 미확인을 남긴다. 초안 전체에 “가설”을 붙인 뒤 검증표에서 미확인을 통과로 바꾸지 않는다. 표현이 새 자격·의무·면제를 암시한다면 주의사항만 덧붙이지 말고 제출할 컨셉 문장 자체를 고친다. 확인되지 않은 새 운영 안내를 덧붙여 오해를 해결하지 않는다. 확인할 수 없는 항목은 보류하고 무한 수정하지 않는다.

## 산출물

기본은 요청한 컨셉 문장과 짧은 설명이다. 전체 워크숍 정리 요청에만 질문·인사이트·경쟁 기회·베네핏·미션·비전·컨셉을 묶는다. 필요한 미확인 사항은 확정 내용과 구분한다.
