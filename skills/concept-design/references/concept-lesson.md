# 컨셉수업 — 호소다 다카히로

개인 독서 메모다. 아래 방법과 사례는 발상에 쓰며 책 원문 전체의 검증이나 해당 기업의 현재 공식 전략 확인을 뜻하지 않는다. 필요한 절만 읽는다.

## 컨셉이란

컨셉은 '전체를 관통하는 새로운 관점'. 새로운 의미를 창조하는 일.
'무엇을 위해 존재하는가'라는 물음으로 비즈니스의 중심을 알 수 있다.

**컨셉 = 가치의 설계도**
1. 판단 기준이 된다
2. 일관성을 부여한다
3. 대가의 이유가 된다

**컨셉 vs 구성요소**: '왜'와 '무엇'의 관계. 흔들림 없는 '왜'가 중심에 있어야 '무엇을', '어떻게'를 시대에 맞게 업데이트할 수 있다.

**컨셉 ≠ 아이디어**: 번뜩이는 생각을 고객 관점에서 재구성한 것이 컨셉.
**컨셉 ≠ 테마**: 테마는 '과제', 컨셉은 '고유한 답'. (예: '의류 산업의 어두운 이면' → '급진적 투명성')

## 효과적인 컨셉의 4조건

1. **고객의 눈높이** — 기뻐하는 고객의 얼굴이 떠오르는 말 (예: 5GB MP3 → 주머니 속의 1000곡)
2. **세상에 단 하나** — 누군가에게 온전히 사랑받으려면 미움받을 각오도 해야 한다. 모두를 기쁘게 하려면 아무도 기쁘게 못한다.
3. **규모 예측** — 비즈니스 목표 달성 가능한 규모인지 검증. 자기만족의 시가 되어선 안 된다.
4. **쉬운 말** — 짧고 기억하기 쉬우며 공유 가능. 기억 못하면 조직 내 공유도 안 된다.

확인할 질문이지 자동 채점표가 아니다. 경쟁·수요·고객 반응 자료가 없으면 관련 항목은 미확인으로 남기고, 초안의 매력을 유일성·시장 규모의 근거로 바꾸지 않는다.

## 질문 설계

좋은 컨셉을 이끌어내려면 조리있는 질문이 필수. 상식적 질문에 의문을 제기하는 데서 시작.

**질문 공식: 자유도 × 임팩트**
- 자유도: 답으로 다양한 방법이 계속 떠오르면 높은 질문
- 임팩트: '넓은 임팩트'(많은 사람 생활 영향) + '깊은 임팩트'(한 사람 인생을 바꿀 만큼)

질문도 정기적으로 검증. 환경 변화로 어리석은 질문이 되기도 한다.

## 재구성 7가지 방법

질문을 바꿔 관점을 전환하고 시야를 넓히는 것.

1. **부분 → 전체**: 세탁기가 아니라, 빨래 바구니에서 개는 것까지 일련의 과정
2. **객관 → 주관**: 데이터에서 못 나오는 파격은 주관에서. 자신만의 개인적 질문으로 시작
3. **현실 → 이상**: 10x 퀘스천. '사고를 줄이다' → '인간 실수 사고를 없애다'
4. **명사 → 동사**: 명사로 생각하면 고정관념. '체중계' → '건강하게 살을 뺀다'
5. **만들기 → 부수기**: '무엇을 만들까' → '무엇을 부술까'
6. **수단 → 목적**: 닌텐도 위의 게임(수단) → '가족 시간을 되찾겠다'(목적)
7. **이기적 → 이타적**: 브랜드는 이기적 질문을 이타적 질문으로. 사회적 가치

## 고객 인사이트

'아직 충족되지 않은 숨겨진 욕구'. 듣는 순간 '듣고 보니 그러네!' 하는 것.

- 말로 표현한 욕구와 실제 행동이 다를 수 있다는 관점이다. 이 메모만으로 의식·무의식의 비율을 정량화하지 않는다
- **인사이트는 갈등 속에 숨겨져 있다**: 'A이지만 B' 기본 구문
- 예: 식사 준비에 품을 들이고 싶지 않지만, 부실하게 먹고 싶지는 않다

## 경쟁자 3층 분석

1. **같은 범주**: 고객이 시장에서 비교/검토하는 상대
2. **같은 과제**: 고객이 이루고자 하는 것(JTBD). 자동차 vs 대중교통, 자전거
3. **같은 시간**: 같은 시간을 사용하는 경쟁자. 출근길 뉴스/팟캐스트/SNS

핵심: 경쟁자의 약점과 고객에 대한 소홀함 → 시장의 빈 곳(기회)

## 자사 강점 분석

1. **팩트**: 객관적 사실 (예: 무게 158g)
2. **메리트**: 사실이 주는 일반적 이익 (예: 읽고 싶은 책을 언제든 손에 넣는다)
3. **베네핏**: 타깃에게 특히 어필하는 이익 (예: 서재를 통째로 옮길 수 있다)

## 4C 인사이트형 스토리

Customer → Competitor → Company → Concept

```
고객이 어려움을 겪는다.
"그러나" 경쟁자가 도와주지 못한다.
"그래서" 자사가 손길을 내민다.
"즉, 그러므로" 컨셉이 해결책이다.
```

## 미션-비전-컨셉 3층 구조 (비전형 스토리)

| 층위 | 정의 | 시간 |
|------|------|------|
| 미션 | 조직의 사회적 사명. 영원히 지속 | 창업 ~ 영원 |
| 비전 | 이상적 미래. 이루어지면 사라진다 | 미래 |
| 컨셉 | 비전을 향한 지금의 최선 | 현재 |

SpaceX 예시: 미션 '인류의 밝은 미래' → 비전 '여러 행성 거주' → 컨셉 '재사용 로켓'

### 미션 작성법
- '지금껏 우리가 만든 것이 수단이라면, 진짜 목적은?'
- 보편성 + 고유성 필요
- 예: 비누 회사 → 여성의 자신감을 만드는 회사

### 비전 작성법
- '보이는 언어'로 표현. 풍경을 스케치할 수 있을 정도로 구체적
- 해상도 높이기: 모호 → 상상 가능 (예: '건강하게' → '100세 노인이 100m 달리기')
- **스트레치 존**에서 써야 한다:
  - 컴포트 존: 현재 능력 범위, 심리적 부담 없음
  - 스트레치 존: 기존 방식으론 안 되지만 비현실적이지 않음 ← 여기
  - 패닉 존: 영원히 실현 안 될 것 같은 수준

## 인사이트형 + 비전형 통합

두 방향을 모두 한번에 고려해야 한다. 컨셉은:
1. 고객 인사이트에 부응하는 내용
2. 조직의 비전을 이루는 첫걸음

**에어비앤비 예시:**
- 인사이트: 처음 가는 마을에서도 이방인 취급 받고 싶지 않다
- 경쟁자: 멋진 숙박 시설은 지역 실제 생활과 동떨어져 있다
- 베네핏: 전 세계 게스트를 맞이하는 호스트 커뮤니티
- 미션: 테크놀로지로 사람들을 하나로 만든다
- 비전: 누구나 전세계 어디든 친구가 있는 시대로
- **컨셉: 전 세계 어디든 내 집처럼**

## 3점 정리법

모든 컨셉은 **'A가 B하기 위해 C 역할을 맡는다'**로 표현 가능.

스타벅스 예시:
- 고객(A): 도시 생활에 지친 사람들이
- 목적(B): 도시에서 편히 쉴 수 있도록
- 역할(C): 직장과 집 사이의 쉼터 역할을 한다

### 유형 결정
- **목적형** (동사): "전 세계 어디든 내 집처럼", "주머니 속의 1000곡"
- **역할형** (명사): "제 3의 장소", "퍼스널 컴퓨터", "급진적 투명성"
- **연결형** (동사+명사): "기름과 소금을 줄이는 건강 요리"

### 압축
영단어 2개 이내는 압축을 시도하는 요령이지 인지 능력의 보편 한계가 아니다. 한국어의 명료한 의미와 사용자가 원하는 길이를 우선한다.
스타벅스: '직장과 집 사이의 쉼터' → **Third Place**

## 표현 감각 3법

1. **연상법** (마인드맵): 중앙 제시어에서 연상 확장. '스마트폰 → 카메라 → 셀카 → 추억 → 졸업앨범 → 3년 후 당신의 스마트폰은 졸업 앨범이 된다'
2. **우연법**: 완전히 다른 영역의 단어에서 시작. 뷰티 + 스포츠 용어 → '뷰티 워밍업'
3. **유의어법**: 핵심 단어의 유의어로 교체. '다시 찾고 싶은 마을' → '돌아가고 싶은 마을'

## 9가지 문장 구문

1. **혁신 화법**: a에서 b로 / a를 b로 (현재 → 변화 후)
2. **비교강조법**: a보다 b / a가 아니라 b (우선순위 전복)
3. **불 해소법**: a가 없는 b / a가 필요없는 b (불만/불안/불쾌 해소)
4. **은유법**: a같은 b (쉽게 떠올릴 수 있고 좋은 인상의 대상)
5. **반전법**: 상식 뒤집기 → 새로운 상식 (예: '작아보이는 브라')
6. **모순법**: a인데 b, 모순 연결 (예: '파자마 정장')
7. **민주화**: a를 모든 사람에게 (예: '컴퓨터를 모든 사람에게')
8. **개인화**: 한 사람에게 하나의 a를 (예: '한 사람당 하나의 방송국')
9. **기호화**: 의미를 수치/도형/단어로 대체 (예: '하루 종일' → '24시간')

## 마케팅 컨셉 작성법

1. 고객 눈높이에서 (전문용어 배제)
2. 멋진 카피보다 기능적 표현에 집중
3. 200~300자로 다듬기

**구조**: 인사이트로 공감 → 베네핏을 근거와 함께 제시 → 컨셉으로 마무리

## 가치(Values)

조직에서 공유할 가치관과 행동 원칙. 짧고 인상적인 몇 가지 문구.

**3조건**: 간단하게 / 명확하게 / 기억하기 쉽게 (운율, 리듬)

**3단계**:
1. **발굴**: 행동/생각을 모조리 꺼내고, 남길 것 / 바꿀 것 분류
2. **선정**: 바꿀 행동 → 이상적 행동으로 전환. 비전/미션과 대조하며 선별
3. **언어화**: 3조건에 맞춰 완성

## 브랜드/제품/커뮤니케이션 컨셉

1. **브랜드 컨셉**: 고객과의 약속. 언제나, 어디서나, 언제까지나 같은 가치
2. **제품 컨셉**: 고객이 구매하는 진짜 이유를 명확하게 하는 말
