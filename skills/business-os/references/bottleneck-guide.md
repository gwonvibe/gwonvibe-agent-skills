# 사업 병목 구분 가이드

병목은 결과가 나빠 보이는 곳이 아니라, 전체 흐름을 실제로 제한하는 곳이다.

| 구간 | 대표 신호 | 먼저 확인할 것 |
|---|---|---|
| 수요 | 문제를 말하는 사람이나 지불 근거가 거의 없음 | 실제 결제자, 현재 대안, 돈·시간을 쓰는 행동 |
| 도달 | 적합한 고객이 상품을 거의 보지 못함 | 노출 대상, 채널별 유입, 도달의 질 |
| 이해·제안 | 방문은 있지만 무엇을 주는지 이해하지 못함 | 고객·문제·결과·구성·가격의 명확성 |
| 신뢰·전환 | 문의·상담은 있지만 결제로 이어지지 않음 | 반대 이유, 증거, 위험, 결제 과정, 부적합 고객 비율 |
| 제공·사용 | 판매는 되지만 완료·사용·만족이 낮음 | 온보딩, 제공 용량, 품질, 고객의 실제 사용 장애물 |
| 재구매·추천 | 첫 구매 뒤 다시 오지 않음 | 상품 특성상 반복이 필요한지, 결과 달성, 다음 필요 |
| 수익·현금 | 매출은 있지만 남는 돈이나 현금이 부족함 | 직접비, 환불, 지원 시간, 수금 시점, 고객 획득비 |

## 병목을 고르는 순서

1. 사업에 실제로 존재하는 흐름만 그린다.
2. 각 구간의 분자·분모·기간을 맞춰 비교한다.
3. 처음으로 명확하게 막히는 구간을 찾는다.
4. 그 구간을 설명할 사실과 가설을 분리한다.
5. 다른 설명을 구별할 가장 작은 확인을 정한다.

예를 들어 방문 대비 결제가 낮아도 방문자의 대부분이 대상 고객이 아니라면 전환 문구보다 도달 품질이 먼저다. 반대로 적합한 문의가 반복되지만 같은 이유로 결제를 멈춘다면 신뢰·제안 구간을 먼저 확인한다.

## 자료가 부족할 때

자료가 없으면 업계 평균이나 임의의 합격선을 넣지 않는다. 다음처럼 표시한다.

- 확인됨: 직접 자료가 병목을 뒷받침함
- 가설: 가능한 설명이지만 경쟁 설명이 남아 있음
- 미측정: 필요한 숫자나 기록이 없음

미측정 상태에서는 대규모 개선안보다 필요한 자료를 얻는 작은 측정을 먼저 제안한다.
