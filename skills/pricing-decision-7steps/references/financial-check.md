# 가격 후보의 재무 조건 확인

이 문서는 가격 후보를 비교하기 위한 기본 계산이다. 세금 신고나 회계 처리를 대신하지 않는다.

## 먼저 단위를 맞춘다

- 같은 통화인가
- 부가세 등 세금 포함·별도 표시가 같은가
- 일회성, 월, 연 결제를 섞지 않았는가
- 고객 한 명 기준인지 주문 한 건 기준인지
- 환불 전 금액인지 환불 반영 금액인지

단위가 다르면 계산보다 먼저 맞춘다.

## 비용 나누기

### 판매 한 건과 함께 늘어나는 비용

- 결제 수수료
- 배송·포장
- 건별 외주 또는 라이선스
- 고객 한 명에게 제공하는 재료
- 판매에 따라 직접 늘어나는 지원 비용

### 기간 전체에 드는 비용

- 임대료
- 기본 구독료
- 고정 인건비
- 제작비와 장비비

비용의 성격은 계약과 운영 방식에 따라 달라질 수 있다. 모르면 임의로 분류하지 않는다.

## 기본 계산

```text
매출 = 실제 판매가 × 판매 수량
건당 공헌이익 = 실제 판매가 − 건당 변동비
전체 공헌이익 = 건당 공헌이익 × 판매 수량
```

건당 공헌이익이 0보다 클 때만 다음 참고값을 계산한다.

```text
손익분기 수량 = 해당 기간의 고정비 ÷ 건당 공헌이익
```

나누어떨어지지 않으면 실제 판매 가능한 정수 수량을 기준으로 올림한다. 이 값은 세금, 대표자 인건비, 환불, 미래 지원 의무를 빠뜨리면 실제 손익과 달라진다.

## 할인과 환불

정가가 아니라 고객이 실제로 낸 평균 금액을 확인한다.

```text
실제 수금 = 결제액 − 할인 − 환불 − 결제 취소
```

아직 받지 못한 외상 매출은 매출 기록과 현금 흐름에서 구분한다. 환불 기간이 끝나지 않았다면 최종 수익으로 단정하지 않는다.

## 서비스의 시간 비용

강의, 컨설팅, 대행처럼 사람 시간이 늘어나는 상품은 다음을 확인한다.

```text
고객당 준비 시간:
고객당 제공 시간:
고객당 사후 지원 시간:
동시에 제공 가능한 고객 수:
추가 고객을 받을 때 필요한 인력·도구:
```

대표자의 시간을 무료라고 두면 낮은 가격이 지속 가능해 보일 수 있다. 다만 시간당 비용을 임의로 정하지 말고 실제 목표 보수나 대체 인력 비용을 사용한다.

## 후보 비교표

| 항목 | 후보 A | 후보 B | 후보 C |
|---|---:|---:|---:|
| 표시 가격 | | | |
| 실제 예상 수금 | | | |
| 건당 변동비 | | | |
| 건당 공헌이익 | | | |
| 예상 수량과 근거 | | | |
| 전체 공헌이익 | | | |

| 빠진 비용·가정 | | | |

후보가 많지 않으면 필요한 열만 사용한다.

## 흔한 오류

- 매출이 가장 큰 후보를 이익이 가장 큰 후보로 착각한다.
- 설문 응답 수를 실제 판매 수량으로 사용한다.
- 월 구독 매출을 연간 매출처럼 비교한다.
- 환불과 지원 비용을 0으로 둔다.
- 고정비를 주문마다 다시 더하거나, 변동비를 한 번만 더한다.
- 가격 인상 뒤 고객군과 제공 범위가 달라졌는데 같은 상품처럼 비교한다.
