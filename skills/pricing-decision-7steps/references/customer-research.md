# 가격 고객 조사

가격 조사는 정답을 묻는 투표가 아니다. 고객이 어떤 대안과 조건을 비교하는지 확인하고, 가격 후보를 검증할 단서를 얻는 과정이다.

## 조사 방법 선택

| 방법 | 알 수 있는 것 | 주의할 점 |
|---|---|---|
| 실제 판매 기록 | 실제 선택, 환불, 재구매 | 과거 고객·채널 조건에 한정됨 |
| 견적·판매 대화 | 거절 이유와 결정 조건 | 기록 방식과 담당자 차이 |
| 사전 주문·소규모 판매 | 실제 지불 행동에 가까운 반응 | 제공과 환불 준비가 필요함 |
| 고객 인터뷰 | 대안, 맥락, 표현 | 말과 실제 행동이 다를 수 있음 |
| 가격 설문 | 가격 인식의 분포 | 구매율이나 매출을 직접 예측하지 못함 |

현재 결정에 필요한 것보다 큰 조사를 만들지 않는다.

## 인터뷰 질문 예시

- 이 문제를 지금은 어떻게 해결하고 있나요?
- 현재 방식에 돈과 시간을 얼마나 쓰고 있나요?
- 다른 상품을 검토했다면 무엇과 비교했나요?
- 구매를 결정하거나 미룬 가장 큰 이유는 무엇이었나요?
- 가격 외에 반드시 필요한 조건은 무엇인가요?
- 이 상품을 사용하지 않는다면 어떤 대안을 선택할 가능성이 큰가요?

“이 가격이면 사실 건가요?”라는 질문 하나로 구매를 예측하지 않는다. 과거 행동과 실제 선택 상황을 함께 묻는다.

## 가격 인식 설문 예시

모든 응답자에게 같은 상품 범위, 결제 주기, 통화를 보여준다. 특정 금액을 미리 암시하지 않고 직접 입력받는 방식을 검토한다.

```text
1. 너무 저렴해서 품질이나 제공 범위가 걱정되는 금액은 얼마인가요?
2. 합리적인 선택이라고 느껴지는 금액은 얼마인가요?
3. 비싸지만 조건에 따라 검토할 수 있는 금액은 얼마인가요?
4. 아무리 필요해도 구매하기 어렵다고 느껴지는 금액은 얼마인가요?
5. 그렇게 답한 가장 큰 이유는 무엇인가요?
```

질문 순서와 표현을 바꾸면 결과도 달라질 수 있으므로 실제 문구를 분석 자료와 함께 보존한다.

## 응답 검토

- 상품 설명을 충분히 본 대상인가
- 목표 고객과 모집 경로가 맞는가
- 통화와 결제 주기가 일치하는가
- 빠진 응답과 잘못된 단위를 어떻게 처리했는가
- 응답자별 금액 순서가 논리적으로 맞는가
- 극단값을 임의로 지우지 않았는가
- 고객군이 다른 응답을 한 분포로 합치지 않았는가

제외하거나 수정한 응답은 기준과 수를 기록한다. 원문을 몰래 고치지 않는다.

## 해석

- 각 질문의 중앙값, 범위, 응답 분포를 먼저 본다.
- 표본이 작거나 한 채널에서만 모였다면 대표성이 제한된다고 표시한다.
- 교점이나 평균 하나만으로 최종 가격을 정하지 않는다.
- 구매 의향과 실제 구매를 구분한다.
- 자유 의견에서 반복되는 조건과 대안을 찾되, 소수 의견을 전체 고객의 말로 확대하지 않는다.

## 조사 운영 경계

- 필요한 정보만 수집하고 목적과 보관 방식을 알린다.
- 보상, 마감, 참여 인원을 만들어내지 않는다.
- 동의받지 않은 명단에 설문을 발송하지 않는다.
- 무응답자를 반복해서 독촉하지 않는다.
- 조사 설계 요청만으로 폼 제작, 발송, 후속 연락을 실행하지 않는다.

