# 가격 설문 분석 — 현재 계산·해석 기준

실제 사용한 질문지의 문구와 응답을 함께 읽는다. 아래는 이 스킬의 계산 규약이며, 설문으로 실제 구매·매출을 예측하는 검증된 수요 모형이라는 뜻은 아니다.

## 1. 입력과 유효 응답

- 분석 대상 상품·통화·일회성/월/연 단위·조사 기간을 고정한다. 다른 상품·주기·질문지를 임의로 합치지 않는다.
- 현재 양식의 Q1=싸다, Q2=비싸지만 구매 가치 있음, Q3=너무 비싸다, Q4=너무 싸서 의심. 다른 순서의 자료는 실제 문구로 이 의미에 대응시킨다. 문구가 없으면 번호만으로 추정하지 않는다.
- 네 가격이 같은 단위의 유한한 비음수이고 Q4 ≤ Q1 ≤ Q2 ≤ Q3인지 확인한다. 결측·단위 혼용·불일치는 수정/제외 사유를 기록하며 임의 보정하지 않는다.
- 교점용 네 곡선은 동일한 유효 응답자 집합과 **N=그 인원수**를 사용한다. N=0이면 계산하지 않는다. 질문별 부분 집계는 각 분모를 따로 표시하고 동일 표본의 곡선처럼 합치지 않는다.
- 집계 자료만 있으면 질문 뜻·분모·제외 기준을 확인한다. 응답자별 일관성을 확인할 수 없다는 한계를 남긴다.
- 40~60명은 과거 자료의 예시다. 표본 수만으로 시장 대표성이나 정밀도를 보장하지 않으며, 소표본·편향은 명시한다.

## 2. 누계·반전

p는 비교할 가격, q1~q4는 각 응답자의 가격이다. 같은 가격축에서 아래 비율을 계산한다. 계산 중에는 반올림하지 않는다.

| 곡선 | 계산 | 방향 |
|---|---|---|
| C1: 싸다 | 100 × count(q1 ≥ p) / N | 비증가 |
| C2: 비싸지만 가치 있음의 응답 임계값 누계 | 100 × count(q2 ≤ p) / N | 비감소 |
| C3: 너무 비싸다 | 100 × count(q3 ≤ p) / N | 비감소 |
| C4: 너무 싸서 의심 | 100 × count(q4 ≥ p) / N | 비증가 |
| I1: C1 반전 | 100 − C1 | 비감소 |
| I2: C2 반전 | 100 − C2 | 비증가 |

같은 가격의 응답 포함 여부는 위 부등호를 따른다. 반전은 누계의 여집합이지 거짓 응답을 탐지하거나 실제 구매자를 찾아내는 절차가 아니다.

## 3. 교점

- 하한 후보: I1 ∩ C4.
- 상한 후보: C3 ∩ I2.
- 관측 가격축의 인접 두 점을 직선으로 연결한 **보간값**임을 표시한다. 관측되지 않은 가격으로 외삽하지 않는다.
- 두 곡선 차이를 d0, d1이라 할 때 부호가 바뀌는 구간의 교점은 p0 + (p1 − p0) × d0 / (d0 − d1)이다. 차이가 0인 끝점은 그대로 교점이다.
- 두 차이가 모두 0이면 겹치는 구간이다. 분모가 0인 식을 계산하지 않는다. 교점 없음·중복/복수·하한>상한은 유일한 가격대 산출 불가로 보고한다.
- 원시 보간값과 표시 단위를 구별한다. 예컨대 1원 단위 표시는 가장 가까운 정수로 하되, 실제 판매가 선택은 별도 판단이다.

기존 연립 예시의 양성 대조: C3 = 0.005p − 30, I2 = −0.014p + 228이면 교점은 p=258000/19≈13578.947, y≈37.895%다. 이것이 상한보다 비싸면 전원이 구매를 거절한다는 뜻은 아니다.

## 4. Q5 — 번호보다 질문 뜻

Q5는 가격 응답과 별도인 구매 **의향**이다. 유효 단일 선택 응답 수 N5로 나눈다. 무응답을 부정 응답으로 바꾸지 않으며, N5=0이면 분포를 계산하지 않는다.

현재 `template-survey.md`의 문구를 사용한 경우:

| 그룹 | 선택지 | 해석 |
|---|---|---|
| 구매 의향 표현 | ①~④ | 사고 싶다고 응답함 |
| 미정 | ⑤ | 살지 모르겠다고 응답함 |
| 부정/관심 없음 | ⑥~⑧ | 소극적·부정적 의향 또는 관심 없음 |
| 강한 의향의 별도 부분집합 | ①+② | 구매 의향 그룹에 포함되며 중복 합산하지 않음 |

각 선택지 원분포도 남긴다. 과거 일반화 질문지처럼 ④가 '모르겠다', ⑤가 '원하지 않는다'인 자료는 그 의미에 맞게 따로 분류한다. 본 양식으로 재번호화하거나 두 질문지의 그룹 비율을 직접 합치지 않는다.

20%·1/3 기준은 원전 독서 메모의 휴리스틱이며 합격/탈락을 결정하는 고정 검증선이 아니다. ①+② 또는 ①~④를 실구매율로 취급하거나 Q5로 매출을 임의로 50% 보정하지 않는다.

## 5. 매출·이익은 별도 자료가 있을 때만

Q2 누계는 가격 인식 임계값의 분포다. 그 누계를 구매 인원으로 곱하지 않는다. Q5에도 특정 가격의 구매 확률이 주어져 있지 않다.

판매 자료나 사용자와 명시적으로 정한 시나리오가 있으면:

- 예상 수량 = 명시된 대상 규모 × 해당 조건의 구매율. 관측값인지 가정인지 표시한다.
- 매출 = 가격 × 수량. 할인·반품·환불은 실제 자료에 맞춰 별도로 반영한다.
- 매출총이익 = 매출 − 해당 판매의 원가.
- 운영·획득·지원 등 다른 비용을 모르면 순이익을 확정하지 않는다. 수금 시점이 다르면 이익과 현금흐름도 분리한다.

가격을 100원 올리면 매출이 반감한다거나 가격 인식 범위 안이면 브랜드가 안전하다고 보장하지 않는다. 원가·고객 대안·실제 전환·제공 능력을 함께 확인한다.

## 결과 기록

- 자료/질문지 식별, 상품·단위·기간·고객군, 원응답 수/N/N5, 제외와 한계
- 곡선·교점·보간/표시 기준 또는 산출 불가 사유
- 선택지별 Q5 분포, 의미별 집계, 사용한 매핑
- 판매 자료가 있을 때만 별도 매출·이익 시나리오와 가정
- 가격 후보·근거·미확인 정보·사용자 확정 여부

실제로 수집하지 않은 Q0·Q6·자유 의견·고객 특성을 채우지 않는다. 기존 시트·표준 라이브러리로 충분하면 새 폼·웹앱·패키지·알림 연동을 만들지 않는다.
