# 감정가격 결정법 — 가격 조사와 해석

스도 코지의 7단계 가격 조사에서 출발한 개인 운영 스킬이다. 가격 인식은 구매 행동·매출·브랜드 안전을 보장하지 않는다.

## 요청 범위와 자료 선택

- 조사 설계: 상품·제공 범위·대상 고객·통화/결제 주기를 확인하고 `references/template-survey.md`를 읽는다.
- 기존 응답 분석: 실제 사용한 질문지와 응답을 먼저 읽고 `references/template-analysis.md`를 따른다. 질문 번호보다 원래 문구의 의미가 우선이다.
- 가격 후보 비교: 목적·고객 대안·비용·제공 여력·기존 판매 근거를 확인한다. 설문이 적합할 때만 추가하며, 이미 확정된 가격이나 상품을 자동으로 다시 설계하지 않는다.
- 출처 대조 요청: `references/sudo-koji-method.md`는 과거 독서 기록으로만 읽는다. 그 안의 예시 수치·옛 공식·문구를 현재 실행 규칙으로 사용하지 않는다.

실제 발송·독촉·보상 약속·개인정보 수집·사이트 제작·가격 변경은 조사나 분석 요청만으로 승인된 것이 아니다.

## 7단계

필요한 단계부터 시작하고 이미 주어진 자료는 다시 만들지 않는다.

1. **목적·대상 확인:** 무엇의 가격을 누구에게 어떤 조건으로 조사하는지 정한다. 기존 팬/비팬 등 필요한 고객군은 구분한다.
2. **질문지 확인 또는 설계:** 가격 인식 4문항과 선택적인 Want 문항의 원문을 보존한다. 응답자에게 동일한 상품·제공 범위를 설명하고, 가격 인식 문항은 유도 가격 없이 받는 것을 기본으로 한다.
3. **응답 검증·집계:** 유효 응답 N, 누계 방향, 경계값 처리는 분석 문서가 단일 기준이다. 40명 같은 예시 숫자를 고정 분모로 쓰지 않는다. 계산은 도구로 수행한다.
4. **가격 인식 교점 확인:** 하한·상한은 표본의 가격 인식 요약이다. 교점이 없거나 여러 개면 그대로 보고하며 억지 가격대를 만들지 않는다.
5. **판매 시나리오 구분:** 실제 전환·수량 자료 또는 명시된 가정이 있을 때만 매출·이익 시나리오를 계산한다. Q2 누계나 Q5 의향을 구매량으로 바꾸지 않는다.
6. **Want 분포 해석:** 사용한 질문지의 의미별 분포를 보고한다. 20% 합격선·1/3 위험선·매출 50% 보정은 범용 규칙으로 적용하지 않는다.
7. **가격 후보 판단:** 조사 결과와 고객 대안·비용·지원 부담·환불·사업 목적을 함께 본다. 추천과 사용자 확정, 실제 가격 반영은 구별한다.

## 출력

요청 범위에 맞게 아래 중 필요한 항목만 제시한다.

- 사용한 질문지·자료·대상·유효 N과 제외 기준
- 가격 인식 범위 또는 산출 불가 사유
- Want 분포와 실제 구매 행동 자료의 구분
- 가격 후보·근거·가정·운영 부담·아직 모르는 것
- 결정에 필요한 다음 확인 하나

타깃·상품 설명이 불명확하거나 표준 시세·경매 등 다른 가격 결정 방식이 핵심이면 이 설문을 억지로 적용하지 않는다. 광고 기반 모델은 이용자와 실제 결제자를 먼저 구별한다.

## 연결과 출처

가격 판단은 이 스킬에서 맡고, 승인된 후속 퍼널·채널 작업만 `growth-marketing`으로 연결한다. 의뢰서·판매 문구가 별도로 필요하면 해당 상품에 맞는 카피 스킬을 사용한다. 다른 Claude 에이전트의 자동 호출 여부를 보장하지 않는다.

출발 자료: 스도 코지, 《비싸야 잘 팔리는 비상식적 마케팅》 5장. 과거 독서 기록은 원전 인용 정확성과 효과를 새로 검증한 자료가 아니다. 현재 문항은 조사 양식, 계산·해석은 분석 문서가 각각 정본이다.
