# 상담·구매·재구매 전환

전환은 사람을 압박해 결제시키는 일이 아니라 고객 상황과 상품의 적합성을 확인하고 결정을 돕는 과정이다.

## 상담 흐름

### 1. 참여 이유를 확인한다

고객이 왜 지금 알아보는지, 어떤 결과를 원하는지 묻는다. 질문에 답하기 전에 이미 정한 결론으로 몰아가지 않는다.

### 2. 현재 상황을 요약한다

들은 내용을 고객의 말에 가깝게 정리하고 맞는지 확인한다. 진단하지 않은 문제를 단정하지 않는다.

### 3. 적합성을 판단한다

```text
필요: 이 상품이 실제 문제를 다루는가
조건: 고객이 필요한 시간·자료·환경을 갖췄는가
결정: 본인 또는 적절한 담당자가 결정할 수 있는가
시점: 지금 시작해야 할 실제 이유가 있는가
예산: 비용과 결제 조건이 가능한가
```

맞지 않으면 판매를 밀어붙이지 않고 이유와 가능한 대안을 설명한다.

### 4. 제안을 연결한다

고객이 말한 문제 → 필요한 해결 방식 → 제공 항목 → 기대 가능한 결과 → 고객이 해야 할 일 순서로 설명한다.

### 5. 질문과 우려를 다룬다

- 내용을 먼저 정확히 확인한다.
- 숨은 반론이라고 추측하지 않는다.
- 답할 수 없는 내용은 확인 후 답한다고 말한다.
- 가격, 일정, 환불, 제공 범위를 임의로 바꾸지 않는다.
- 거절을 존중하고 반복 압박하지 않는다.

## 근거와 보증

- 후기는 사용 동의와 실제 조건을 확인한다.
- 특별히 좋은 사례를 평균 결과처럼 말하지 않는다.
- 통제할 수 없는 성과를 보장하지 않는다.
- 환불, 추가 지원, 성과 조건은 비용과 이행 가능성을 검토하고 승인된 정책만 사용한다.
- 실제로 없는 마감, 남은 자리, 가격 인상 계획을 만들지 않는다.

## 낮은 가격의 대안

가격을 깎기 전에 제공 범위를 줄인 별도 상품이 고객 문제를 해결할 수 있는지 본다.

```text
유지할 핵심 결과:
제외할 선택 기능:
줄어드는 지원 범위:
새 가격과 조건:
기존 고객 권리에 미치는 영향:
```

이미 계약하거나 약속한 권리를 마케팅 판단으로 축소하지 않는다.

## 재구매와 추천

- 구매 직후 사용 시작을 돕는다.
- 고객이 처음 작은 결과를 얻는 지점을 확인한다.
- 문의와 이탈 이유를 제품 개선에 반영한다.
- 다음 상품은 실제 다음 필요가 있을 때만 제안한다.
- 추천과 후기는 만족을 확인한 뒤 선택적으로 요청한다.
- 연락 중단 요청은 즉시 반영한다.

## 전환 점검

- 문의에 대한 응답 시간이 지나치게 길지 않은가
- 신청 뒤 다음 단계가 명확한가
- 상담 예약과 실제 참석 사이에서 막히지 않는가
- 가격과 제공 범위가 모든 화면에서 일치하는가
- 구매 뒤 사용 시작 방법이 전달되는가
- 환불·해지·문의 방법을 찾을 수 있는가
