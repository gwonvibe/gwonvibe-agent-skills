## CLOSER 세일즈 프레임워크

고가 세일즈 상담을 위한 개인 요약 6단계다. 실제 필요·적합성을 확인하고 거절을 존중한다. 원전 문구를 그대로 옮긴 인용으로 취급하지 않는다.

| 단계 | 행동 |
|------|------|
| **C** - Clarify | 고객이 참여한 진짜 이유 파악 |
| **L** - Label | 문제와 현재 단계를 분류해줌 |
| **O** - Overview | 상황 요약 → "내 상황을 정확히 안다"는 신뢰 |
| **S** - Sell the Trip | 과정이 아니라 결과(목적지)에 집중 |
| **E** - Explain Resistance | 예산/타이밍 등 반론 정면 돌파 (회피 금지) |
| **R** - Reinforce | 비행동의 대가(Cost of Inaction) 강조 → 결정 확고화 |

---

## 프루프 스택 (Proof Stack)

증거를 양으로 압도하여 성취 가능성 인식을 극대화.

**구성 요소** (약한 것 → 강한 것):
텍스트 후기 < 스크린샷/데이터 < 비포/애프터 < 케이스 스터디 < 반복적 성공

**배치 원칙**:
- 약속 직후에 증거 (VSL: 약속 → 증거 → 해결 계획)
- 고가/고관여일수록 증거량을 늘려야

---

## 반론 처리 3단계

1. 고객 언어로 FAQ 선제 구성 (판매자 용어 금지)
2. 대표 반론 정면 돌파 (예산, 타이밍 등)
3. 비행동의 대가(Cost of Inaction) 강조

---

## 보증 유형 4가지 (강도순)

| 유형 | 설명 | 적합 조건 |
|------|------|----------|
| 환불+페널티 | 실패 시 전액 환불 + 추가 보상 | 고가 서비스, 결과 통제 가능 |
| 추가 지원 보증 | 합의한 범위 안의 추가 작업 | 기간·횟수·원가·통제 가능성과 사용자 승인이 확인됐을 때만 |
| 성과 기반 | 결과 달성 시에만 과금 | B2B/에이전시, 마진 충분 시 |
| 행동 조건부 | 고객이 조건 이행했는데도 실패 시 보상 | 교육/코칭에 최적, 가장 균형 |

**B2B 주의**: 통제 불가 변수가 많은 영역에서 과도한 보증 = 사기처럼 보임.
대안: 한계 솔직 인정 + 위험 관리 프로세스 제시 + 노하우 공유.
**원칙: 보증 강도는 통제 가능성에 비례한다.**

## USR 전환 촉진

- **U** - Urgency: 시간 압박 ("이번 달 2자리만")
- **S** - Scarcity: 자격/수량 제한 ("ARR 50만+ 기업만")
- **R** - Risk Reversal: 위험 제거 (보증)

실제로 존재하는 제한과 허용된 보증만 선택한다. 마감·수량 제한이 없는 상품에는 해당 항목을 생략한다. 가짜 희소성·임의 마감·승인되지 않은 환불/성과 약속을 만들지 않는다.

---

## BANT 리드 검증

세일즈 통화 전 신청서/예약 시스템에 질문 내장:
- **B**udget: 예산이 있는가
- **A**uthority: 의사결정 권한이 있는가
- **N**eed: 실제 필요가 있는가
- **T**iming: 지금 구매할 시점인가

충족 → 세일즈 집중. 미충족 → 너처링으로 이동.

---

## 5-Touch 너처링 시퀀스

```
Day 0:  리드 자석 전달 + 환영
Day 1:  추가 가치 + 소프트 피치
Day 3:  케이스 스터디 / 증거
Day 7:  FAQ + 반론 극복
Day 14: 다음 행동 안내 (실제 마감이 있을 때만 알림)
```

**감정 설계**: Give → Give → Prove → De-risk → Close
가치→증거→질문 해소→다음 행동의 예시다. 실제 자료·동의·관계에 맞게 내용과 일수를 정한다. 발송·후속 연락 종료는 `hormozi-outreach-playbook.md` 공통 원칙을 따른다.

## 슈퍼팬 식별

무료 콘텐츠 배포 → 소비 깊이/참여도 추적 → 최고 참여자 = 최우선 세일즈 대상.
BANT(살 수 있는가)와 다른 축: 참여도(살 의향이 있는가).

---

## 비적격 리드의 간접 가치

버리지 않는다. 3가지 경로로 수익 기여:
1. 시간차 전환: 상황 변화 시 유료 고객으로
2. 추천 (Referral): 다른 유료 고객 연결
3. 후기 (Social Proof): 무료 경험의 긍정 후기 → 마케팅 자산

- [ ] 1:1 지원 → 셀프서비스

## 후기 재생산 시스템

```
성과 고객 인터뷰 → 성공 행동 패턴 추출
→ 신규 고객에게 동일 행동 유도
→ 효과를 확인한 행동만 온보딩·합의된 보증 조건에 반영
→ 실제 성과를 다시 측정하고 동의받은 후기 수집
```
