# Offer Design — Alex Hormozi

> 거절할 수 없는 제안(Grand Slam Offer)을 설계하는 프레임워크.

---

## 가치 방정식 (Value Equation)

```
가치 = (꿈꾸는 결과 × 성취 가능성 인식) ÷ (소요 시간 × 노력과 희생)
```

### 분자 극대화

**꿈꾸는 결과 (Dream Outcome)**
- 기능/수치가 아닌 감정 상태와 변화를 묘사
- 동료 시선에서 본 지위 상승으로 포장 ("친구들 입이 벌어질 것")

**성취 가능성 인식 (Perceived Likelihood)**
- Proof Stack: 후기, 데이터, 비포/애프터, 반복적 성공을 양으로 압도
- 리스크 리버설: 보증으로 고객 위험을 판매자가 흡수 → 상세는 `hormozi-sales-conversion.md`
- 범위 축소: 포함 항목을 줄여 "이것만 하면 된다"는 명확성
- 프레이밍: 실제 근거와 제공 방식에 맞는 표현. 검증하지 않은 시스템을 검증됐다고 부르지 않는다.

### 분모 최소화

**소요 시간 압축**
- Quick Win: 프로세스 초기에 작은 성공 배치
- 기간 프레이밍: 체감 기간을 구체적 숫자로 단축 (달성 가능 범위 내)
- 즉시 제공: 온보딩/딜리버리 지연 제거

**노력 제거**
- DIY → DWY → DFY 스펙트럼에서 위치 결정 (DFY일수록 고가)
- 마찰 프레이밍: "초보자 친화", "따라하기만 하면"
- 단계 최소화: 고객이 해야 할 행동 수 자체를 줄임

**심리적 해결책**
- 주의 분산 (거울 패턴): 대기 시간 자체를 잊게 만듦
- 진행 시각화 (지도 패턴): 진전되고 있음을 보여줌
- 물리적 개선보다 인식 개선이 비용 효율적일 수 있음

## Grand Slam Offer 조립 4단계

1. **Dream Outcome 정의**: 고객의 최종 목표 한 문장
2. **장애물 나열**: 달성 전/후 모든 문제 + 과거 거절 사유
3. **문제 → 해결책 변환**: "How to ~" 형태로 뒤집기
4. **Trim & Stack**:
   - 제거: 비용 高 + 가치 低
   - 유지: 비용 低 + 가치 高 (Sweet Spot)
   - 번들: 남은 해결책에 매력적 이름 → 하나로 묶기

## 니치 다운 가격 레버

```
일반($19) → 직업군($99) → 직무($499) → 초정밀 니치($1,997)
```

니치별 가격은 가능성을 설명하는 예시이지 검증된 배수·가격표가 아니다. 좁은 타깃의 수요·고객 대안·제공 가치를 확인한다. 실제 가격 판단은 `pricing-decision-7steps`가 담당한다.

## 가치 사다리 (Value Ladder)

```
DIY (직접 하기)  → DWY (함께 하기) → DFY (대행)
저가              중가              고가
고객 노력 高     고객 노력 中       고객 노력 0
```

---

## 제안 검증 (광고비 투입 전)

1. 적합한 고객에게 제안을 보여주는 검증을 설계한다. 10명은 탐색 예시이며 발송·모집은 승인 범위 안에서만 한다.
2. 반응과 그 이유, 실제 지불·신청 등 행동을 구분한다.
3. 무반응만으로 타겟 문제를 확정하지 않는다. 도달 여부·대상·제안·표현·채널을 자료에 따라 확인한다.

**확인 순서 예시**: 타겟 → 제안 → 카피 → 채널. 이미 확인된 원인이 있으면 그 근거를 우선한다.
