# 리드 확보 장치 설계

리드 확보 장치는 잠재 고객이 연락처나 신청 정보를 남길 만한 구체적인 도움이다. 무료 자료, 진단, 체험, 상담 신청 등이 될 수 있다.

## 좋은 장치의 조건

- 한 사람의 좁고 분명한 문제를 다룬다.
- 약속한 작은 결과를 그 자체로 완성한다.
- 소비 방법과 완료 기준이 분명하다.
- 핵심 해결책이나 안전 정보를 일부러 빼지 않는다.
- 다음 유료 상품은 실제로 생기는 다음 필요를 해결한다.
- 받는 정보와 후속 연락에 대해 명확히 동의받는다.

## 만드는 순서

### 1. 문제 순간을 고른다

“마케팅이 어려운 사람”보다 “판매 페이지를 열었지만 첫 문장을 못 쓰는 사람”처럼 상황을 좁힌다.

### 2. 작은 결과를 정한다

```text
사용 전: 무엇이 없거나 어려운가
사용 후: 어떤 결과물이 남는가
완료 확인: 스스로 무엇을 확인할 수 있는가
```

### 3. 형식을 고른다

| 형식 | 잘 맞는 상황 | 주의할 점 |
|---|---|---|
| 체크리스트·PDF | 기준과 순서를 전달할 때 | 읽고 끝나지 않게 행동을 넣는다 |
| 템플릿·도구 | 결과물을 바로 만들 때 | 입력 방법과 예시를 제공한다 |
| 영상·미니 강의 | 시연이 이해에 중요할 때 | 자막이나 글 요약을 제공한다 |
| 진단·퀴즈 | 상황별 다음 행동이 다를 때 | 결과 기준과 개인정보 범위를 밝힌다 |
| 체험·상담 | 직접 경험과 대화가 필요할 때 | 제공 범위와 종료 조건을 알린다 |

제작하기 쉬운 형식보다 고객이 실제로 사용할 형식을 고른다.

### 4. 신청 흐름을 줄인다

약속한 자료 제공에 필요하지 않은 정보를 받지 않는다. 왜 수집하는지, 어떤 후속 안내가 오는지, 어떻게 중단할 수 있는지 알린다.

### 5. 자연스러운 다음 행동을 연결한다

무료 자료로 작은 결과를 완성한 뒤 더 넓은 적용, 맞춤 피드백, 시간 절약, 복잡한 문제 해결이 필요할 때 유료 제안을 소개한다. 일부러 새 문제나 불안을 만들지 않는다.

## 점검표

- 제목과 실제 내용이 일치하는가
- 다운로드나 신청 절차가 필요 이상으로 길지 않은가
- 모바일에서도 사용할 수 있는가
- 유료 상품 없이도 약속한 작은 결과를 만들 수 있는가
- 연락처 수집과 후속 안내 동의가 분리되어 있는가
- 제공, 열람, 다음 행동을 각각 측정할 수 있는가
