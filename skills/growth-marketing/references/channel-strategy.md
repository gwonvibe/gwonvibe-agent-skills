# 유입 채널 선택과 운영

채널은 유행보다 고객이 실제로 있는 곳, 현재 만들 수 있는 방식, 결과를 측정할 수 있는지를 기준으로 고른다.

## 채널 유형

| 유형 | 예시 | 장점 | 먼저 확인할 점 |
|---|---|---|---|
| 직접 접촉 | 기존 고객 안내, 이메일, DM, 영업 대화 | 빠른 반응과 대화 | 관계, 동의, 발송 범위 |
| 콘텐츠 | 블로그, 뉴스레터, 영상, 소셜 게시물 | 신뢰와 검색 자산 축적 | 제작 능력, 지속 가능성 |
| 추천·제휴 | 고객 추천, 파트너 협업 | 신뢰를 빌릴 수 있음 | 보상, 책임, 고객 적합성 |
| 유료 노출 | 검색 광고, 소셜 광고, 후원 | 빠른 도달과 측정 | 예산, 추적, 손실 한도 |

## 선택 기준

```text
고객 접근성: 목표 고객이 실제로 있는가
메시지 적합성: 상품을 설명하기 좋은 형식인가
실행 가능성: 현재 시간·기술·예산으로 운영 가능한가
측정 가능성: 다음 행동까지 연결해서 볼 수 있는가
학습 속도: 결과를 판단할 만큼 반응을 얻을 수 있는가
위험: 비용, 개인정보, 브랜드 훼손 가능성은 어떤가
```

이미 잘 작동하는 채널은 담당자가 지루하다는 이유로 버리지 않는다. 새 채널은 기존 채널의 병목이 확인됐거나 별도의 고객군에 도달해야 할 때 검토한다.

## 콘텐츠 기본 구조

```text
문제 순간: 고객이 언제 멈추는가
핵심 도움: 이번 콘텐츠가 해결할 한 가지
근거: 사례, 시연, 자료 중 무엇으로 보여줄 것인가
내용: 이해와 실행에 필요한 설명
다음 행동: 자연스럽게 이어지는 한 단계
```

첫 문장은 내용을 정확하게 예고해야 한다. 충격, 공포, 미해결 질문으로 붙잡아 놓고 약속한 답을 미루지 않는다.

콘텐츠 성과는 채널 목적에 맞게 본다. 인지도 목적이라면 도달과 적합한 반응, 신청 목적이라면 클릭 뒤 신청까지 연결해 확인한다.

## 아웃리치 기본 구조

### 기존 관계

1. 관계와 최근 맥락을 확인한다.
2. 상대에게 실제로 해당할 수 있는 문제를 짧게 묻는다.
3. 도움이 될 때만 자료나 제안을 소개한다.
4. 거절하거나 관심이 없으면 종료한다.

### 새로운 상대

1. 공개된 정보 안에서 대상 적합성을 확인한다.
2. 연락한 이유를 구체적으로 밝힌다.
3. 상대 상황에 맞는 도움을 짧게 제안한다.
4. 부담 없는 다음 행동과 수신 거부 방법을 알린다.

확인하지 않은 칭찬이나 공통점을 만들어 개인화하지 않는다. 무응답은 동의가 아니며, 후속 횟수와 종료 기준을 실행 전에 정한다.

## 실행 계획

고정된 게시 횟수나 발송량을 모든 채널에 적용하지 않는다.

```text
선택 채널:
고객이 있는 근거:
운영할 형식:
감당 가능한 빈도와 기간:
목표 행동:
측정 방법:
비용·불만·오류 중단선:
```
