## 리드 자석 7단계

### 1. 문제 정의
좁고 구체적인 하나의 문제를 다룬다. 예시의 고객 규모·기간·성과 수치는 실제 달성 근거가 있을 때만 약속으로 쓴다.

### 2. 해결책 제공
- 고객 문제 진단 (현재 상태를 보여줌)
- 샘플/체험판 제공
- 다단계 해결 과정 중 핵심 첫 1단계 제공

### 3. 포맷 결정
| 포맷 | 강점 | 적합 조건 |
|------|------|----------|
| 소프트웨어/도구 | 즉각 결과, 소비 쉬움, 전환에 유리할 수 있음 — 실제 비교 필요 | 제작 비용 감당 가능 |
| 정보 (PDF/영상/코스) | 제작 쉬움 | 차별화 어려움 인지 |
| 서비스 (무료 컨설팅) | 전환율 높음 | 스케일 불필요 시 |
| 물리적 제품 | 높은 인지 가치를 줄 수 있음 (Thud Factor) | 배송 비용 감당 가능 |

### 4. 제목 테스트
제목 예시 구조: `[숫자] + [형용사] + [타겟] + [결과] + [기간]`. 입증하지 않은 수치·기간은 채워 넣지 않는다.
네이밍 발전: 문제 정의 → 작동하는 해결책 → 매력적 이름으로 포장.
A/B 테스트: 제목, 이미지, 부제목 조합.

### 5. 소비 마찰 제거
계정 생성, 다운로드, 복잡한 절차 제거. 빠르고 간편하게.

### 6. 과잉 전달
"이게 무료라고?" 수준. 리드 자석 자체가 독립적 가치를 가져야 함.

### 7. CTA
다음 행동 + 지금 해야 하는 이유를 명확히.

## 문제-해결 사이클 (X without Y)

리드 자석이 문제 A를 완전히 해결 → 문제 B가 드러남 → Core Offer가 문제 B 해결.

- 프레첼 전략: 무료 프레첼(배고픔 해결) → 갈증 유발 → 유료 음료
- 첫 단계만 제공: 전체 과정을 갈망하게 만듦
- 진단 도구: 방치할수록 악화되는 문제를 고객 스스로 깨닫게

**판매 타이밍**: 고객에게 실제 다음 필요가 드러난 때를 검토한다. 인위적 문제·불안·제한을 만들어 판매하지 않는다.

## 안티패턴 5가지

1. **저품질**: 무료 ≠ 대충. 시간 비용 대비 가치 없으면 브랜드 훼손
2. **넓은 타겟**: "모두를 위한" = 아무도 반응 안 함
3. **약한 제안**: "무료 상담" → 구체적 가치 명시로 리프레이밍
4. **완벽주의**: 구조(X→Y 연결)는 미리, 품질은 반복으로 개선
5. **막다른 해결**: Core Offer로 연결 안 되는 리드 자석은 구조적 실패
