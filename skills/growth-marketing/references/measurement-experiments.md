# 퍼널 측정과 성장 실험

수치는 답을 자동으로 알려주지 않는다. 같은 대상, 기간, 조건을 맞춰 비교하고 수치가 말하지 못하는 원인은 별도로 확인한다.

## 기본 계산

### 단계 전환율

```text
전환율 = 다음 행동 수 ÷ 해당 단계에 들어온 수 × 100
```

예: 판매 페이지 방문 200회 중 신청이 10회라면 방문에서 신청으로 넘어간 비율은 5%다. 방문이 0이면 전환율을 계산하지 않는다.

### 고객 획득 비용

```text
고객 획득 비용 = 같은 기간의 획득 비용 ÷ 신규 유료 고객 수
```

광고비만 포함했는지 제작·영업비까지 포함했는지 범위를 표시한다. 신규 고객이 0명이면 숫자를 억지로 만들지 않는다.

### 매출과 이익

매출, 실제 수금, 매출원가, 운영비를 섞지 않는다. 매출이 늘어도 환불, 제공 비용, 미수금 때문에 현금과 이익이 줄 수 있다.

고객 생애가치는 관찰 기간과 매출 기준인지 이익 기준인지 밝힌다. 짧은 기간의 평균을 장기간으로 늘려 잡았다면 가정이라고 표시한다.

## 퍼널 표

| 단계 | 들어온 수 | 다음 행동 수 | 전환율 | 이전 기간과 조건 | 메모 |
|---|---:|---:|---:|---|---|

서로 다른 채널, 고객군, 기간을 한 줄에 섞지 않는다. 추적이 끊긴 값과 실제 0을 구분한다.

## 병목 판단

다음을 함께 비교한다.

```text
영향: 개선되면 최종 목표가 얼마나 달라지는가
근거: 반복된 수치나 고객 반응이 있는가
통제: 현재 팀이 바꿀 수 있는가
비용: 실험 비용과 실패 손실은 얼마인가
선행 조건: 다른 단계가 먼저 고쳐져야 하는가
```

비율이 낮아도 의도적으로 대상자를 거르는 단계라면 병목이 아닐 수 있다.

## 실험 카드

```markdown
### 실험 이름
- 관찰한 문제:
- 원인 가설:
- 바꿀 한 가지:
- 그대로 둘 것:
- 대상과 범위:
- 주요 측정값:
- 부작용을 볼 측정값:
- 판단할 기간 또는 표본:
- 중단 조건:
- 실행 승인 여부:
```

주요 측정값만 좋아지고 환불, 불만, 운영 시간이 악화될 수 있으므로 부작용도 함께 본다.

## 결과 기록

```markdown
- 시작 전 기준값:
- 실험 중 실제 변경:
- 결과:
- 외부 변화:
- 확실히 알게 된 것:
- 아직 모르는 것:
- 결정: 유지 / 수정 / 중단 / 보류
- 다음 행동:
```

작은 표본의 한 번 좋은 결과를 일반 법칙으로 만들지 않는다. 여러 변경을 동시에 했다면 무엇이 원인인지 분리하기 어렵다고 기록한다.

## 실행 전 안전선

- 광고: 총예산과 일일 한도
- 아웃리치: 승인된 대상과 수량, 수신 거부 처리
- 판매: 승인된 가격, 보증, 환불 조건
- 개인정보: 필요한 정보만 수집하고 보관·삭제 기준 확인
- 고객 경험: 불만, 오류, 환불이 늘 때의 중단 조건
