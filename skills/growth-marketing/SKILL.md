# Growth Marketing

비즈니스를 성장시키기 위한 실행 체계. 제안 설계 → 채널 선택 → 리드 확보 → 세일즈 전환 → 측정/최적화의 전체 파이프라인을 다룬다.

## 경계 규칙 (CRITICAL)

이 스킬은 **"무엇을, 어디서, 얼마나, 어떤 순서로"**를 다룬다.
제안의 가치·근거·메시지는 필요한 만큼 다루되, 상세 심리 분석과 원고 제작은 별도 요청에 맞는 스킬로 넘긴다.

기존 목표·상품·자료를 재사용한다. 아래 방법·수치는 개인 운영 참고이며 보편적 효과를 보장하지 않는다. 발송·게시·광고비·명단 수집·가격/보증 변경은 계획 요청만으로 승인되지 않는다.

| 필요한 것 | 참조할 스킬 |
|----------|-----------|
| 심리 원리 (앵커링, 손실 회피, 사회적 증거 등) | `behavioral-science` |
| 카피 작성 (헤드라인, CTA, 본문) | 현재 사용 가능한 작업별 카피 스킬 |
| 설득 페이지 구조 / 전환 체크리스트 | 현재 사용 가능한 페이지·UX 검토 스킬 |
| 브랜드 전략 / 포지셔닝 | `branding` |

## 체계 개요

```
[100M Money Model — 수익 아키텍처]
    │
    ├── 1. 제안 설계 (Offer Design)
    │   가치 방정식 → Grand Slam Offer → 니치 다운 → 가치 사다리
    │
    ├── 2. 채널 전략 (Channel Strategy)
    │   Core Four → 채널 선택 → 100의 법칙 → More/Better/New
    │
    ├── 3. 리드 확보 (Lead Generation)
    │   리드 자석 7단계 → 문제-해결 사이클 (X without Y)
    │
    ├── 4. 세일즈 전환 (Sales Conversion)
    │   CLOSER → 보증 설계 → USR → 다운셀 → 너처링
    │
    └── 5. 측정/최적화 (Measurement)
        사슬 방법론 → KPI 추적 → 70/20/10 배분
```

## 적용 워크플로우

### 새 비즈니스 / 새 제안을 설계할 때

요청한 새 제안에 필요한 자료만 읽는다. 기존 퍼널 개선 요청이면 아래 최적화 경로를 사용하되, 다른 사업의 매출이 있다는 이유로 새 제안 설계를 거절하거나 재진단하지 않는다.

1. `references/hormozi-offer-design.md` 읽기 — 가치 방정식으로 제안 설계
2. `references/hormozi-channel-strategy.md` 읽기 — 채널 선택 + 실행 규율
3. 리드 확보 장치가 필요할 때만 `references/hormozi-lead-magnet.md` 읽기. 이미 정해진 요소는 다시 설계하지 않는다.

### 기존 퍼널을 최적화할 때

1. `references/hormozi-channel-strategy.md`의 사슬 방법론 — 병목 구간 찾기
2. 병목이 리드 확보 → `references/hormozi-lead-magnet.md`
3. 병목이 세일즈 전환 → `references/hormozi-sales-conversion.md`
   - 전환이 구조적으로 안 되면 리드 자석의 X without Y 연결이 깨진 것일 수 있음 → `references/hormozi-lead-magnet.md`의 안티패턴 5번 + 문제-해결 사이클 재점검
4. 병목이 실행량 → 시간·예산·허용 범위 안에서 해당 채널의 실행량 결정. 100의 법칙은 예시이지 의무가 아니다.

### 채널별 실행이 필요할 때

- 아웃리치 → `references/hormozi-outreach-playbook.md`
- 콘텐츠 → `references/hormozi-content-playbook.md`
